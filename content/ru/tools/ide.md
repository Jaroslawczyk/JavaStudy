**IDE** (Integrated Development Environment, интегрированная среда разработки) — это редактор кода, компилятор, отладчик, система сборки, Git-клиент и сотни подсказок в одном окне. Для Java хорошая IDE экономит часы каждый день: автодополнение, рефакторинги, поиск ошибок ещё до запуска, генерация кода.

## Коротко: что выбрать

| Ситуация | Рекомендация |
|---|---|
| Вы новичок и учите Java | **IntelliJ IDEA** (бесплатная часть) — как в видеокурсе |
| Студент / преподаватель | **IntelliJ IDEA Ultimate** бесплатно по образовательной лицензии |
| Слабый ноутбук (4–8 ГБ ОЗУ) | **VS Code** + Extension Pack for Java или Eclipse |
| Пишете на нескольких языках (Java + JS/Python) | **VS Code** или IntelliJ IDEA Ultimate |
| Работа в компании | Чаще всего **IntelliJ IDEA Ultimate**, лицензию оплачивает работодатель |
| Старый enterprise / банки / встраиваемые системы | Встречается **Eclipse** (и Spring Tools на его базе) |

## IntelliJ IDEA (JetBrains)

Безусловный лидер для Java и Kotlin: по опросам JetBrains и Snyk ею пользуются около 70–80 % Java-разработчиков. Именно её используют в видеокурсе.

**Сильные стороны:** лучший анализ кода и рефакторинги, «умное» автодополнение, встроенные Maven/Gradle, Git, терминал, отладчик, поддержка Spring, баз данных, Docker, HTTP-клиент (в Ultimate).

**Слабые стороны:** требовательна к памяти (комфортно — от 16 ГБ ОЗУ), расширенные функции платные.

### Бесплатно или платно (актуально с версии 2025.3)

С версии **2025.3** больше нет отдельных Community и Ultimate — есть **один IntelliJ IDEA**:

- **Без подписки** — полноценная IDE для Java и Kotlin, бесплатно и для коммерческой работы: всё, что было в Community Edition, плюс мастер Spring Boot, базовая подсветка Spring/Jakarta EE/Thymeleaf, подключение к базам данных и SQL.
- **Подписка Ultimate** — полная поддержка Spring/Jakarta EE/Quarkus/Micronaut, профайлер, HTTP-клиент, продвинутые инструменты баз данных, удалённая разработка и т.д. Есть 30-дневный пробный период. Цена для частных лиц — порядка $17–20 в месяц, при годовой оплате дешевле, со второго года действуют скидки (актуальные цены — на [jetbrains.com/idea/buy](https://www.jetbrains.com/idea/buy/)).
- **Бесплатный Ultimate**: студентам и преподавателям ([образовательная лицензия](https://www.jetbrains.com/community/education/)), мейнтейнерам open-source проектов, участникам некоторых буткемпов.

:::tip
Если вы студент — оформите образовательную лицензию с университетской почтой или ISIC-картой. Это полноценный Ultimate на весь срок обучения.
:::

### Live Templates — сокращения кода

Напишите сокращение и нажмите <kbd>Tab</kbd>:

| Сокращение | Во что превращается |
|---|---|
| `psvm` или `main` | `public static void main(String[] args) { }` |
| `sout` | `System.out.println();` |
| `soutv` | `System.out.println("x = " + x);` — вывод последней переменной |
| `souf` | `System.out.printf("");` |
| `fori` | `for (int i = 0; i < ; i++) { }` |
| `iter` | цикл for-each по последней коллекции/массиву |
| `ifn` / `inn` | `if (x == null)` / `if (x != null)` |

Свои шаблоны добавляются в *Settings → Editor → Live Templates*.

### Полезные настройки

- *Settings → Editor → General → Auto Import* → включите **Add unambiguous imports on the fly** и **Optimize imports on the fly** — импорты будут добавляться и чиститься сами.
- *Settings → Tools → Actions on Save* → **Reformat code** и **Optimize imports** при сохранении.
- *Settings → Editor → Code Editing → Quick Documentation* → документация при наведении мыши.
- *Help → Change Memory Settings* — увеличьте память IDE до 2–4 ГБ, если проект большой и всё тормозит.
- Вкладка **Learn** на стартовом экране — встроенный интерактивный тренажёр по возможностям IDE. Пройдите его в первую неделю.

## Visual Studio Code + Extension Pack for Java

Бесплатный лёгкий редактор от Microsoft. Java-поддержку дают расширения, прежде всего **Extension Pack for Java** (ядро — языковой сервер от Red Hat на базе Eclipse JDT).

- **Плюсы:** бесплатно, быстро запускается, мало памяти, один редактор для всех языков, отлично работает с GitHub Codespaces, Dev Containers, удалёнными серверами по SSH.
- **Минусы:** рефакторинги и анализ кода слабее IDEA, большие многомодульные проекты индексируются медленнее, больше ручной настройки.
- **Где используют:** full-stack разработчики, DevOps, те, кто пишет на нескольких языках; учебные курсы с облачными средами.

Для Spring добавьте **Spring Boot Extension Pack**. Подробнее — в статье [Плагины для IDE](#/tools/plugins).

:::note "Редакторы с ИИ"
Cursor, Windsurf и подобные «ИИ-редакторы» построены на базе VS Code, поэтому Java в них настраивается теми же расширениями. Про ИИ-инструменты — отдельная страница [ИИ](#/page/ai).
:::

## Eclipse IDE

Старейшая бесплатная open-source IDE (Eclipse Foundation, лицензия EPL). Новые версии выходят раз в квартал (формат `2026-09`).

- **Плюсы:** полностью бесплатна, мощный компилятор с инкрементальной сборкой, огромная экосистема плагинов, работает на слабых машинах.
- **Минусы:** устаревший интерфейс, хуже автодополнение и рефакторинги, чем в IDEA; доля на рынке постепенно падает.
- **Где используют:** крупные банки и корпорации с давней историей, встраиваемые системы, проекты на Eclipse RCP. На её базе сделаны **Spring Tools** (бывший Spring Tool Suite).

Скачивайте сборку **Eclipse IDE for Enterprise Java and Web Developers** или **for Java Developers** на [eclipse.org/downloads](https://www.eclipse.org/downloads/packages/).

## Apache NetBeans

Бесплатная IDE от Apache Software Foundation (когда-то — официальная IDE Sun/Oracle).

- **Плюсы:** всё «из коробки» без плагинов, удобный визуальный редактор Swing-интерфейсов, хорошо подходит для обучения.
- **Минусы:** небольшое сообщество, в коммерческой разработке встречается редко.

## Другие варианты

- **JShell** — консоль Java в терминале (`jshell`), идеальна для экспериментов с одной-двумя строками.
- **Онлайн-компиляторы**: [OneCompiler](https://onecompiler.com/java), [JDoodle](https://www.jdoodle.com/online-java-compiler) — запустить код с телефона или чужого компьютера.
- **GitHub Codespaces** — VS Code в браузере с готовым Linux-окружением; бесплатные часы для личных аккаунтов.
- **BlueJ / Greenfoot** — учебные среды для школьников с визуализацией объектов.

:::

## Домашнее задание

:::task easy "Пройдите тренажёр"
Откройте в IntelliJ IDEA вкладку **Learn** на стартовом экране и пройдите модули *Onboarding Tour* и *Editor Basics*.
:::

:::task easy "Шпаргалка горячих клавиш"
Выпишите на стикер 5 сочетаний из таблицы выше и неделю используйте только их вместо мыши. Включите плагин **Key Promoter X** — он будет подсказывать сочетание каждый раз, когда вы кликаете мышью по действию.
:::

:::task medium "Свой Live Template"
Создайте шаблон `todo`, который вставляет комментарий `// TODO(ваше_имя): ` с текущей датой. Используйте переменную шаблона `date()`.
??? Подсказка
*Settings → Editor → Live Templates → +* → Live Template. Текст: `// TODO(anna, $DATE$): $END$`. Нажмите *Edit Variables* и для `DATE` выберите выражение `date("yyyy-MM-dd")`. Не забудьте внизу указать контекст *Java*.
:::

:::task hard "Один проект — две IDE"
Создайте простой Maven-проект в IntelliJ IDEA, загрузите его в Git, а потом откройте ту же папку в VS Code (с Extension Pack for Java) и запустите `main` там. Сравните: скорость запуска, подсказки, отладку. Запишите три отличия.
??? Подсказка
Maven-проект (с файлом `pom.xml`) — переносимый формат: любая IDE понимает его структуру. Папки `.idea/` и `.vscode/` — личные настройки IDE, их обычно добавляют в `.gitignore`.
:::
