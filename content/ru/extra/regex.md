**Регулярные выражения** — язык шаблонов для поиска, проверки и замены текста: валидация e-mail, разбор логов, извлечение чисел из строки. В Java они живут в пакете `java.util.regex` и используются также в `String.matches`, `split`, `replaceAll`.

## Основы синтаксиса

| Шаблон | Значение |
|---|---|
| `.` | любой символ (кроме перевода строки) |
| `\d`, `\w`, `\s` | цифра, «буква/цифра/_», пробельный символ |
| `\D`, `\W`, `\S` | всё, кроме перечисленного |
| `[abc]`, `[a-z]`, `[^0-9]` | набор символов, диапазон, отрицание |
| `^`, `$` | начало и конец строки |
| `*`, `+`, `?` | 0+, 1+, 0 или 1 раз |
| `{3}`, `{2,5}` | ровно 3, от 2 до 5 раз |
| `(…)`, `(?<name>…)` | группа, именованная группа |
| `a\|b` | или |
| `\b` | граница слова |

:::warning "Двойной обратный слэш"
В строковом литерале Java обратный слэш экранируется: шаблон `\d+` пишется как `"\\d+"`, точка — `"\\."`. В текстовых блоках (`"""`) правило то же.
:::

## Pattern и Matcher

```java
private static final Pattern PHONE = Pattern.compile("\\+48\\s?(\\d{3})[\\s-]?(\\d{3})[\\s-]?(\\d{3})");

Matcher m = PHONE.matcher("Звоните: +48 501-234 567 или +48501234568");
while (m.find()) {
    System.out.println(m.group() + " → " + m.group(1) + m.group(2) + m.group(3));
}

boolean ok = PHONE.matcher(input).matches();       // вся строка целиком соответствует?
```

- `Pattern.compile` дорогой — компилируйте шаблон **один раз** в `static final`, а не в цикле. `String.matches(regex)` каждый раз компилирует заново.
- `matches()` — вся строка, `find()` — следующее вхождение, `lookingAt()` — начало строки.

## Именованные группы и замена

```java
Pattern DATE = Pattern.compile("(?<day>\\d{2})\\.(?<month>\\d{2})\\.(?<year>\\d{4})");
Matcher m = DATE.matcher("09.10.2026");
if (m.matches()) {
    int year = Integer.parseInt(m.group("year"));
}

"09.10.2026".replaceAll("(\\d{2})\\.(\\d{2})\\.(\\d{4})", "$3-$2-$1");   // 2026-10-09
"a1b22c333".replaceAll("\\d+", "#");                                      // a#b#c#
DATE.matcher(text).replaceAll(r -> r.group("year"));                      // Java 9: функция замены
DATE.matcher(text).results().map(MatchResult::group).toList();            // Java 9: стрим совпадений
```

## Флаги

```java
Pattern.compile("hello", Pattern.CASE_INSENSITIVE | Pattern.UNICODE_CASE);
Pattern.compile("(?i)привет");                  // флаг внутри шаблона
Pattern.compile("^\\s*#.*$", Pattern.MULTILINE); // ^ и $ для каждой строки
```

:::warning "ReDoS: катастрофический возврат"
Шаблоны с вложенными квантификаторами вроде `(a+)+$` или `(\\w+\\s?)*$` на специально подобранной строке работают экспоненциально долго — сервер «зависает» на одном запросе. Не применяйте сложные регулярки к пользовательскому вводу без ограничения длины; используйте притяжательные квантификаторы (`a++`) и атомарные группы (`(?>…)`), а для e-mail/URL — готовые валидаторы.
:::

:::tip "Когда regex не нужен"
Для простых задач хватает `String`: `startsWith`, `contains`, `strip`, `isBlank`, `chars()`. Для разбора JSON, HTML, CSV используйте парсеры (Jackson, jsoup, Commons CSV), а не регулярные выражения.
:::

:::

Затем найдите в интернете пример уязвимого к ReDoS шаблона, измерьте время на строках длины 20, 25, 30 и исправьте его.
:::
