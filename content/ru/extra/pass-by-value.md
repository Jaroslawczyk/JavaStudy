«В Java объекты передаются по ссылке, а примитивы по значению» — популярное, но **неточное** утверждение. Правильно: **в Java всё передаётся по значению**. Просто для объектов значением является ссылка. Разберём, почему метод может изменить объект, но не может «подменить» его.

## Примитивы

```java
static void increment(int x) {
    x++;                          // меняем КОПИЮ
}

int a = 5;
increment(a);
System.out.println(a);            // 5
```

## Ссылки на объекты

Переменная ссылочного типа хранит не объект, а **ссылку** (адрес) на объект в куче. При вызове метода копируется эта ссылка.

```java
static void rename(Car car) {
    car.setName("BMW");           // через копию ссылки меняем ТОТ ЖЕ объект
}

static void replace(Car car) {
    car = new Car("Audi");        // меняем только копию ссылки
}

Car myCar = new Car("Lada");
rename(myCar);
System.out.println(myCar.getName());   // BMW — объект изменился
replace(myCar);
System.out.println(myCar.getName());   // BMW — подмена не видна снаружи
```

```
до вызова:   myCar ──┐
                     ▼
                [Car "Lada"]
в rename:    car ────┘   (две ссылки на один объект)

в replace:   car ──▶ [Car "Audi"]    myCar по-прежнему ──▶ [Car "BMW"]
```

## Классический тест: swap

```java
static void swap(Integer a, Integer b) {
    Integer tmp = a; a = b; b = tmp;      // переставили копии ссылок
}

Integer x = 1, y = 2;
swap(x, y);
System.out.println(x + " " + y);          // 1 2 — ничего не поменялось
```

В языке с настоящей передачей по ссылке (C++ `int&`, C# `ref`) `swap` сработал бы. В Java написать такой `swap` невозможно — это и есть доказательство передачи по значению.

## Неизменяемые объекты

```java
static void append(String s) { s = s + "!"; }

String text = "Hi";
append(text);
System.out.println(text);                  // Hi
```

`String`, `Integer` и другие обёртки неизменяемы: «изменение» создаёт новый объект, и новая ссылка остаётся в локальной копии.

## Как вернуть несколько значений или «изменить» аргумент

- Вернуть результат: `x = increment(x);`
- Вернуть несколько значений — `record Result(int min, int max)`.
- Передать изменяемый контейнер (массив, `AtomicInteger`, свой объект) — метод изменит его содержимое.

:::interview "Вопрос с собеседования"
**В Java передача по ссылке или по значению?** — Всегда по значению. Для ссылочных типов копируется значение ссылки, поэтому метод может изменить состояние переданного объекта, но не может сделать так, чтобы переменная вызывающего кода указывала на другой объект.
:::
