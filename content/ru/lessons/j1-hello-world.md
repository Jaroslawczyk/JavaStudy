## Структура проекта

После создания проекта в IntelliJ IDEA слева видна панель **Project**. Главное в ней — папка **`src`** (source, исходники): весь Java-код лежит там. В проектах Maven/Gradle путь длиннее: `src/main/java` для кода и `src/test/java` для тестов.

Весь код на Java пишется **внутри классов**, а каждый публичный класс хранится в отдельном файле с расширением **`.java`**. Имя файла обязано совпадать с именем публичного класса: класс `HelloWorld` → файл `HelloWorld.java`.

## Первая программа

```java
public class HelloWorld {

    public static void main(String[] args) {
        System.out.println("Hello World");
    }
}
```

Разберём по частям:

| Фрагмент | Что означает |
|---|---|
| `public` | Модификатор доступа: класс виден из любых других классов (подробно — в уроке о модификаторах доступа) |
| `class HelloWorld` | Объявление класса с именем `HelloWorld` |
| `{ ... }` | Тело класса — всё, что относится к классу, пишется между фигурными скобками |
| `public static void main(String[] args)` | Метод `main` — **точка входа**: с него JVM начинает выполнение программы |
| `System.out.println("...")` | Вызов метода, который печатает строку в консоль и переводит курсор на новую строку |
| `;` | Каждая инструкция (statement) заканчивается точкой с запятой |

Пока считайте `public static void main(String[] args)` «заклинанием» — каждое слово разберём позже: `static` — в уроке о статических членах, `void` — в уроке о методах, `String[] args` — массив аргументов командной строки (урок о массивах).

:::tip "Быстрый ввод"
В IntelliJ IDEA наберите `psvm` (или `main`) и нажмите <kbd>Tab</kbd> — появится метод `main`. Наберите `sout` + <kbd>Tab</kbd> — появится `System.out.println();`. Значок ▶ слева от класса появляется только когда в классе есть `main`.
:::

## Соглашения об именовании

Компилятору всё равно, как вы назовёте класс, но все Java-разработчики следуют единым правилам — код других людей читается легче:

| Что | Стиль | Пример |
|---|---|---|
| Классы, интерфейсы, records, enum | **UpperCamelCase** (PascalCase) | `HelloWorld`, `BankAccount` |
| Методы и переменные | **lowerCamelCase** | `main`, `printReport`, `userName` |
| Константы | **UPPER_SNAKE_CASE** | `MAX_SIZE`, `DEFAULT_TIMEOUT` |
| Пакеты | строчные буквы, через точку | `com.example.shop` |

Java **чувствительна к регистру**: `System` и `system` — разные слова, и второе не скомпилируется.

## Что не рассказано в видео

### print, println и printf

```java
System.out.print("Без перевода строки. ");
System.out.println("С переводом строки.");
System.out.printf("Имя: %s, возраст: %d%n", "Анна", 25);   // форматированный вывод
System.out.println("Строка 1\nСтрока 2\tс табуляцией и \"кавычками\"");
```

- `print` — печатает без перевода строки, `println` — с переводом.
- `printf` — форматирование: `%s` — строка, `%d` — целое, `%.2f` — дробное с 2 знаками, `%n` — перевод строки.
- Escape-последовательности: `\n` — новая строка, `\t` — табуляция, `\"` — кавычка, `\\` — обратный слэш.

### Комментарии

```java
// однострочный комментарий

/* многострочный
   комментарий */

/**
 * Javadoc-комментарий: из него генерируется документация.
 */
```

### Типичные ошибки новичка

- Пропущена `;` → `';' expected`.
- Имя файла не совпадает с именем публичного класса → `class X is public, should be declared in a file named X.java`.
- `system.out.println` с маленькой буквы → `package system does not exist`.
- Строка в одинарных кавычках `'Hello'` — так пишутся только символы (`char`), строки — в двойных.

:::outdated "Мастер нового проекта"
В новых версиях IDEA мастер *New Project* сразу спрашивает **Build system** (IntelliJ / Maven / Gradle) и JDK, а галочка **Add sample code** сама создаёт класс `Main` с `main`. Для учёбы подойдёт *IntelliJ*; для реальных проектов выбирают Maven или Gradle. Окно «Tip of the Day» по умолчанию больше не показывается.
:::

:::outdated "С Java 25 класс и public static не обязательны"
Начиная с **Java 25** (JEP 512 «Compact Source Files and Instance Main Methods») простую программу можно написать без объявления класса и без `public static`:

```java
void main() {
    IO.println("Hello World");
}
```

Класс `java.lang.IO` (Java 25) содержит простые методы `IO.println(...)`, `IO.print(...)` и `IO.readln(...)` для ввода-вывода. Это сделано для обучения и скриптов. В реальных проектах по-прежнему пишут классы и `public static void main(String[] args)` — поэтому обязательно знайте классическую форму.
:::

:::task easy "Визитка"
Выведите «визитку» в рамке из символов `*`: имя, город, любимый язык программирования. Рамка должна быть ровной.

```text
***********************
*  Анна               *

***********************
```

:::task easy "Одной инструкцией"
Выведите те же имена членов семьи **одним** вызовом `System.out.println`, используя `\n`. А потом — используя `print` без `ln`.
:::

:::task medium "Таблица через printf"
С помощью `printf` выведите таблицу из трёх товаров с ровными колонками: название (ширина 10), количество (ширина 5), цена с двумя знаками после запятой.
??? Подсказка
Ширина задаётся числом в спецификаторе: `%-10s` — строка шириной 10, выравнивание по левому краю; `%5d` — целое шириной 5; `%8.2f` — дробное шириной 8 с двумя знаками.
```java
System.out.printf("%-10s %5d %8.2f%n", "Кофе", 2, 15.5);
```
:::

:::task hard "Аргументы командной строки"
Напишите программу, которая печатает `Привет, <имя>!`, где имя передаётся при запуске: `java Greeter.java Анна`. Если аргумент не передан, печатайте `Привет, мир!`. Настройте передачу аргумента и в IDEA (*Run → Edit Configurations → Program arguments*).
??? Подсказка
Аргументы попадают в массив `args`: первый — `args[0]`, количество — `args.length`. Условный оператор `if` разберём через пару уроков, но здесь он нужен в простейшем виде:
```java
if (args.length > 0) {
    System.out.println("Привет, " + args[0] + "!");
} else {
    System.out.println("Привет, мир!");
}
```
:::
