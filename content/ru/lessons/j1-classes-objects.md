## Класс и объект

**Класс** — шаблон, чертёж: описание того, какими свойствами и поведением обладают объекты. **Объект** (экземпляр класса) — конкретная вещь, созданная по этому чертежу.

> «Собака — животное с четырьмя лапами, хвостом и шерстью, которое лает» — это **класс**.
> Шарик из вашего двора — чёрный, небольшой, по кличке Шарик — это **объект**.

Класс состоит из **членов класса**:

- **поля** (переменные экземпляра) — данные: длина, кличка, возраст;
- **методы** — действия: посчитать объём, полаять (следующий урок).

```java
public class Box {
    double width;
    double height;
    double length;
}
```

## Создание объектов

```java
public class Main {
    public static void main(String[] args) {
        Box myBox = new Box();      // создать объект и сохранить ссылку на него
        myBox.height = 10.2;        // доступ к полям — через точку
        myBox.length = 15;
        myBox.width = 11.3;

        double volume = myBox.height * myBox.width * myBox.length;
        System.out.println("Объём коробки: " + volume);   // 1728.9…
    }
}
```

- `Box myBox` — объявить переменную типа `Box` (пока пустую).
- `new Box()` — создать новый объект в памяти. `new` всегда означает «создать новый».
- Каждый объект хранит **свои копии полей**: изменение размеров `box2` не влияет на `box3`.

:::note "Один публичный класс — один файл"
Класс `Box` лежит в файле `Box.java`, а `Main` — в `Main.java`. Класс без `main` нельзя «запустить» — его объекты создаются и используются из других классов.
:::

## Ссылочные переменные

Переменные `myBox`, `box2`, `box3` хранят не сами объекты, а **ссылки** (адреса) на них:

```java
Box box3 = new Box();
box3.height = 10; box3.width = 10; box3.length = 10;

Box box4 = box3;        // НЕ новая коробка: вторая ссылка на тот же объект
box4.height = 100;

System.out.println(box3.height);   // 100 — изменился и box3!
```

```text
box3 ──┐
       ├──►  [ Box: height=100, width=10, length=10 ]
box4 ──┘
```

Отсюда важные следствия:

- `box3 == box4` сравнивает **ссылки** — `true`, это один объект. Две разные коробки с одинаковыми размерами через `==` равны не будут (вспомните строки и `equals`).
- Примитивы (`int`, `double`…) хранят **значение**, и `int b = a;` — это копия.

## Что не рассказано в видео

### Где живут объекты: стек и куча

- **Стек (stack)** — локальные переменные методов: примитивы и *ссылки*. Очищается автоматически при выходе из метода.
- **Куча (heap)** — все объекты, созданные через `new`.
- **Сборщик мусора (Garbage Collector)** сам удаляет объекты из кучи, когда на них не осталось ни одной ссылки. В Java не нужно освобождать память вручную, как в C/C++.

### null и NullPointerException

```java
Box box = null;          // переменная никуда не указывает
box.height = 5;          // NullPointerException!
```

`null` — «пустая ссылка». Обращение к полю или методу через `null` — самая частая ошибка в Java. С Java 14 сообщение подробное: `Cannot assign field "height" because "box" is null`.

### Значения полей по умолчанию

Поля объекта, в отличие от локальных переменных, получают значения по умолчанию: числа — `0`, `boolean` — `false`, ссылки — `null`. Поэтому `new Box()` создаёт коробку с размерами `0.0`.

### Четыре принципа ООП

На собеседованиях их спрашивают почти всегда — вот краткий ориентир; каждый подробно разобран в следующих уроках:

| Принцип | Суть |
|---|---|
| **Инкапсуляция** | Данные и методы — вместе в классе, детали реализации скрыты (`private`) |
| **Наследование** | Новый класс расширяет существующий (`extends`) и переиспользует его код |
| **Полиморфизм** | Один интерфейс — разные реализации; объект подкласса используется там, где ждут родителя |
| **Абстракция** | Выделяем существенное, скрываем лишнее (абстрактные классы, интерфейсы) |

:::outdated "Классы-данные сегодня — record"
Для классов, которые просто хранят данные (как `Box` или `Person` из домашнего задания), с Java 16 есть **record** — компактная форма, где конструктор, геттеры, `equals`, `hashCode` и `toString` генерируются автоматически:

```java
public record Person(String name, int age, double weight) { }
```

Но сначала обязательно разберитесь с обычными классами — records мы обсудим в статье [Records](#/extra/records).
:::

:::task medium "Самый старший"
Создайте массив из пяти объектов `Person` и найдите самого старшего человека и самого лёгкого. Выведите их имена.
??? Подсказка
Храните не возраст, а **ссылку** на найденного человека: `Person oldest = people[0];` и в цикле `if (p.age > oldest.age) oldest = p;`.

Перебирайте все пары двумя вложенными циклами: `for (int i = 0; i < n; i++) for (int j = i + 1; j < n; j++)`.
