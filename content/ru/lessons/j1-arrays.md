**Массив** — группа однотипных переменных под одним именем. Если переменная — коробочка для одного значения, то массив — ящик с пронумерованными ячейками строго одного типа и строго заданного размера.

## Создание массива

```java
int[] daysInMonths = new int[12];   // 12 ячеек типа int, все равны 0
daysInMonths[0] = 31;   // январь
daysInMonths[1] = 28;   // февраль
daysInMonths[2] = 31;   // март

int march = daysInMonths[2];
System.out.println(march);   // 31
```

- `int[]` — тип «массив целых чисел».
- `new int[12]` — создать массив на 12 элементов. **Размер нельзя изменить** после создания.
- Индексы — от `0` до `length - 1`. У массива из 12 элементов последний индекс — 11.

Короткая форма — сразу со значениями (разобрана в следующем уроке):

```java
int[] days = {31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};
```

## Перебор в цикле и length

```java
for (int i = 0; i < daysInMonths.length; i++) {
    System.out.println(daysInMonths[i]);
}
```

:::warning "ArrayIndexOutOfBoundsException"
Обращение к несуществующему индексу роняет программу: `Index 12 out of bounds for length 12`. Поэтому в условии цикла пишите `i < array.length`, а не число `12` и не `<=`.
:::

Научитесь читать такие ошибки (stack trace) в консоли: там указаны тип исключения, сообщение и строка кода, где всё сломалось — по ней можно кликнуть.

## Значения по умолчанию

При создании через `new` все элементы получают значения по умолчанию:

| Тип элементов | Значение по умолчанию |
|---|---|
| `int`, `long`, `short`, `byte` | `0` |
| `double`, `float` | `0.0` |
| `char` | `'\u0000'` (невидимый «нулевой» символ) |
| `boolean` | `false` |
| Ссылочные (`String`, объекты) | `null` |

## Цикл for-each

```java
int[] nums = new int[100];
for (int i = 0; i < nums.length; i++) {
    nums[i] = i * 10;            // изменяем — нужен обычный for с индексом
}

for (int num : nums) {           // «для каждого num в nums»
    System.out.println(num);     // только читаем — удобен for-each
}
```

- for-each не может выйти за границы и не требует индексов.
- **Изменить элементы через переменную for-each нельзя**: присваивание `num = 5` меняет копию, а не массив.
- Тип переменной совпадает с типом элементов: для `char[]` — `for (char ch : chars)`.

## Разбор домашнего задания из видео

```java
int[] first = new int[900];
for (int i = 0; i < first.length; i++) {
    first[i] = i + 100;                  // 100, 101, …, 999
}

int[] second = new int[first.length];
for (int i = 0, j = first.length - 1; i < first.length; i++, j--) {
    second[j] = first[i];                // первый → в конец второго
}

for (int value : second) {
    System.out.println(value);           // 999, 998, …, 100
}
```

:::note "Неточность в задании"
В задании сказано «значения от 100 до 1000», а в решении массив на 900 элементов даёт числа **от 100 до 999**. Чтобы включить 1000, нужен размер 901. Это хороший урок: при работе с диапазонами всегда проверяйте границы.
:::

## Что не рассказано в видео

### Класс Arrays — готовые инструменты

```java
import java.util.Arrays;

int[] a = {5, 3, 9, 1};
System.out.println(a);                    // [I@1b6d3586 — адрес, а не содержимое!
System.out.println(Arrays.toString(a));   // [5, 3, 9, 1]
Arrays.sort(a);                           // [1, 3, 5, 9]
int[] copy = Arrays.copyOf(a, a.length);  // независимая копия
Arrays.fill(a, 0);                        // [0, 0, 0, 0]
boolean same = Arrays.equals(a, copy);    // сравнение содержимого
```

### Массив — это ссылочный тип

```java
int[] a = {1, 2, 3};
int[] b = a;        // НЕ копия: обе переменные указывают на один массив
b[0] = 100;
System.out.println(a[0]);   // 100!
```

Подробно про ссылки — в уроке о классах и объектах.

### Двумерные массивы

```java
int[][] matrix = new int[3][4];      // 3 строки по 4 столбца
matrix[1][2] = 7;
int[][] table = {{1, 2}, {3, 4}, {5, 6}};
for (int[] row : table) {
    System.out.println(Arrays.toString(row));
}
```

### Массив vs коллекции

Массив фиксированного размера — это низкоуровневая структура. В реальном коде гораздо чаще используют `ArrayList`, который растёт сам. Коллекции — в следующих уроках; там же вы поймёте, как `ArrayList` устроен внутри **на основе массива**.

### String[] args

Теперь понятно, что `String[] args` в методе `main` — массив строк с аргументами командной строки.

:::task video "Массив в обратном порядке — из видео"
Создайте массив и заполните его в цикле значениями от 100 до 1000. Создайте второй массив того же размера (используйте `.length`) и заполните его значениями первого в обратном порядке — берите значения именно из первого массива. Выведите второй массив циклом for-each. {{t j1 1:28:59}}
??? Подсказка
В `for` можно объявить две переменные через запятую: `for (int i = 0, j = first.length - 1; i < first.length; i++, j--)`. Решение разобрано в видео: {{t j1 1:30:50}}
:::

:::task easy "Сумма, минимум, максимум"
Дан массив `{12, -5, 7, 0, 33, 8}`. Одним проходом посчитайте сумму, среднее (дробное!), минимальный и максимальный элемент.
??? Подсказка
Начальные значения: `min = array[0]`, `max = array[0]` — не `0`, иначе для массива из отрицательных чисел максимум будет неверным.
:::

:::task easy "Поиск элемента"
Напишите программу, которая ищет число в массиве и печатает его индекс или `-1`, если такого числа нет.
:::

:::task medium "Разворот на месте"
Разверните массив **без второго массива**: меняйте местами первый и последний элементы, второй и предпоследний и т.д. Проверьте на массивах чётной и нечётной длины.
??? Подсказка
Цикл до середины: `for (int i = 0; i < a.length / 2; i++)`, меняем `a[i]` и `a[a.length - 1 - i]` через временную переменную.
:::

:::task hard "Пузырьковая сортировка"
Отсортируйте массив по возрастанию алгоритмом «пузырька» вручную (без `Arrays.sort`). Затем добавьте оптимизацию: если за проход не было ни одного обмена — массив уже отсортирован, выходим. Сравните результат с `Arrays.sort`.
??? Подсказка
Внешний цикл — проходы, внутренний — сравнение соседних элементов `a[j] > a[j + 1]` и обмен. После каждого прохода наибольший элемент «всплывает» в конец, поэтому внутренний цикл можно укорачивать: `j < a.length - 1 - i`.
:::
