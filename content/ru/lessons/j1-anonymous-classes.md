## Обычный способ

```java
public interface Cookable {
    void cook();
}

public class Director {
    public void force(Cookable cookable) {
        cookable.cook();
    }
}

public class Cooker implements Cookable {
    @Override
    public void cook() {
        System.out.println("Готовлю");
    }
}
```

```java
Director director = new Director();
director.force(new Cooker());
```

## Анонимный класс

```java
director.force(new Cookable() {        // класс без имени, реализующий Cookable
    @Override
    public void cook() {
        System.out.println("Готовлю");
    }
});
```

`new Cookable() { … }` одновременно **объявляет** класс без имени и **создаёт** его объект. Внутри фигурных скобок — реализация всех абстрактных методов интерфейса. Анонимный класс может также наследовать обычный или абстрактный класс: `new Animal() { … }`.

Типичное применение — **слушатели (listeners)**: обработчик нажатия кнопки в Android, Swing, JavaFX — объект, у которого вызовут метод, когда произойдёт событие.

:::outdated "Сегодня вместо анонимных классов — лямбды"
Если у интерфейса **ровно один абстрактный метод** (такой интерфейс называется **функциональным**), начиная с Java 8 его реализуют **лямбда-выражением**:

```java
director.force(() -> System.out.println("Готовлю"));
```

Все обработчики событий, `Runnable`, `Comparator` в современном коде пишут лямбдами. Анонимный класс по-прежнему нужен, когда методов несколько, нужно состояние (поля) или наследование от класса. Лямбды и функциональные интерфейсы подробно — во второй части курса и в статье [Функциональное программирование](#/extra/functional).
:::

## Что не рассказано в видео

### Захват переменных

Анонимный класс (и лямбда) может использовать локальные переменные из окружающего метода, но только **effectively final** — те, которые после присваивания не меняются:

```java
String dish = "борщ";
director.force(new Cookable() {
    @Override
    public void cook() {
        System.out.println("Готовлю " + dish);   // OK
    }
});
// dish = "суп";   // если раскомментировать — ошибка компиляции выше
```

### Как он называется на самом деле

Компилятор всё же даёт анонимному классу имя: `Main$1`, `Main$2`… — такие файлы `.class` вы увидите в папке сборки. Он относится к **вложенным классам** (nested classes) — подробно в статье [Вложенные классы](#/extra/nested-classes).

### Когда анонимный класс — плохая идея

Если реализация большая (десятки строк) или нужна в нескольких местах — выносите в обычный именованный класс: его можно протестировать и переиспользовать.
