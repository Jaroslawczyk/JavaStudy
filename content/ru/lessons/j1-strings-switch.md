## Инициализация массива значениями

```java
int[] daysOfMonths = {31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};
String[] namesOfMonths = {
        "Январь", "Февраль", "Март", "Апрель",
        "Май", "Июнь", "Июль", "Август",
        "Сентябрь", "Октябрь", "Ноябрь", "Декабрь"
};
```

Размер вычисляется автоматически, `new` писать не нужно.

## Строки String

`String` — **ссылочный** тип (класс), а не примитивный, но пользоваться им очень просто:

```java
String name = "Иван";
int age = 33;
String result = "Привет, \"" + name + "\"!\nТебе " + age + " года.";
System.out.println(result);
```

Вывод:

```text
Привет, "Иван"!
Тебе 33 года.
```

| Спецсимвол | Значение |
|---|---|
| `\n` | перенос строки |
| `\t` | табуляция |
| `\"` | двойная кавычка внутри строки |
| `\'` | одинарная кавычка (в `char`) |
| `\\` | обратный слэш |

## Разбор задачи: месяцы через запятую

```java
String result = "";
for (int i = 0; i < namesOfMonths.length; i++) {
    result += namesOfMonths[i];
    if (i == namesOfMonths.length - 1) {
        result += ".";
    } else {
        result += ", ";
    }
}
System.out.println(result);   // Январь, Февраль, …, Декабрь.
```

:::tip "Так короче"
```java
String result = String.join(", ", namesOfMonths) + ".";
```
`String.join` склеивает элементы через разделитель. А при склейке в цикле большого количества строк используйте `StringBuilder` — `+=` каждый раз создаёт новую строку (см. ниже).
:::

## Оператор switch

Когда одна переменная сравнивается со многими значениями, цепочка `if-else` становится громоздкой. Классический `switch`:

```java
int numberOfMonth = 5;
switch (numberOfMonth) {
    case 1:
        System.out.println("Январь");
        break;
    case 2:
        System.out.println("Февраль");
        break;
    // …
    case 5:
        System.out.println("Май");
        break;
    default:
        System.out.println("Месяц не существует");
        break;
}
```

:::warning "Проваливание (fall-through)"
Если забыть `break`, выполнение «проваливается» в следующие `case` без проверки условий: при `numberOfMonth = 1` без `break` выведутся январь, февраль, март… до первого встреченного `break`. Иногда это используют намеренно — чтобы объединить несколько значений (как в домашнем задании).
:::

```java
switch (month) {
    case "Декабрь":
    case "Январь":
    case "Февраль":
        System.out.println("Зима");
        break;
    // …
}
```

`switch` работает с `int`, `char`, `byte`, `short`, их обёртками, `String` (с Java 7) и `enum`.

:::outdated "Новый switch (Java 14+)"
Современный Java-код использует **switch со стрелками** — без `break` и без проваливания, с несколькими значениями через запятую. А **switch-выражение** сразу возвращает значение:

```java
String season = switch (month) {
    case "Декабрь", "Январь", "Февраль" -> "Зима";
    case "Март", "Апрель", "Май"        -> "Весна";
    case "Июнь", "Июль", "Август"       -> "Лето";
    case "Сентябрь", "Октябрь", "Ноябрь" -> "Осень";
    default -> "Несуществующее время года";
};
```

Если в ветке нужно несколько строк кода — блок `{ … yield значение; }`. С Java 21 в `switch` можно сопоставлять и **типы** (pattern matching): `case Integer i when i > 0 -> …`. Старый синтаксис по-прежнему работает и встречается в легаси-коде — знать нужно оба.
:::

## Сравнение строк: == и equals

```java
String first = "Java";
String second = new String("Java");

System.out.println(first == second);         // false — разные объекты!
System.out.println(first.equals(second));    // true — одинаковое содержимое
```

- `==` для ссылочных типов сравнивает **ссылки** (тот же ли это объект в памяти).
- `equals` сравнивает **содержимое**.
- **Строки всегда сравнивайте через `equals`** (или `equalsIgnoreCase` без учёта регистра).

Почему `==` «иногда работает»: одинаковые строковые литералы Java хранит в **пуле строк** и переиспользует один объект. Но строки, полученные из ввода, файла или склейки, — новые объекты, и `==` даст `false`. Подробнее — в части 2 курса, в вопросах с собеседований.

:::tip "Защита от null"
`"Зима".equals(season)` не упадёт, даже если `season == null`, а `season.equals("Зима")` выбросит `NullPointerException`. Ещё вариант — `Objects.equals(a, b)`.
:::

## Что не рассказано в видео

### Строки неизменяемы (immutable)

Любой «изменяющий» метод возвращает **новую** строку, исходная не меняется:

```java
String s = "java";
s.toUpperCase();          // результат потерян!
s = s.toUpperCase();      // "JAVA" — нужно присвоить
```

Поэтому склейка в цикле через `+=` создаёт тысячи лишних объектов. Для этого есть `StringBuilder`:

```java
StringBuilder sb = new StringBuilder();
for (int i = 0; i < 1000; i++) {
    sb.append(i).append(", ");
}
String result = sb.toString();
```

### Самые нужные методы String

| Метод | Пример | Результат |
|---|---|---|
| `length()` | `"Java".length()` | `4` |
| `charAt(i)` | `"Java".charAt(0)` | `'J'` |
| `toUpperCase()` / `toLowerCase()` | `"Java".toUpperCase()` | `"JAVA"` |
| `contains(s)` | `"Java".contains("av")` | `true` |
| `indexOf(s)` | `"Java".indexOf("a")` | `1` |
| `substring(from, to)` | `"Java".substring(1, 3)` | `"av"` |
| `replace(a, b)` | `"Java".replace("a", "o")` | `"Jovo"` |
| `strip()` / `trim()` | `"  hi ".strip()` | `"hi"` |
| `isEmpty()` / `isBlank()` | `"  ".isBlank()` | `true` |
| `split(regex)` | `"a,b,c".split(",")` | `["a", "b", "c"]` |
| `startsWith` / `endsWith` | `"Java".endsWith("va")` | `true` |
| `repeat(n)` (Java 11) | `"ab".repeat(3)` | `"ababab"` |
| `formatted(...)` (Java 15) | `"%s=%d".formatted("x", 5)` | `"x=5"` |
