## ООП и основы

:::task video "1. Принципы ООП. Что такое полиморфизм? Пример из жизни."
{{t j2 7:23:51}}
??? Ответ
Инкапсуляция, наследование, полиморфизм (+ абстракция). Полиморфизм — «один интерфейс, много реализаций»: метод, принимающий интерфейсный тип, ведёт себя по-разному в зависимости от реального объекта. Пример — автомобили с одинаковым управлением, но разным поведением.
:::

:::task video "2. Что такое перегрузка? Можно ли методы с одинаковым именем, отличающиеся только типом возврата?"
{{t j2 7:24:44}}
??? Ответ
Перегрузка — методы с одним именем и разными параметрами (количеством, типами, порядком) в одном классе. Отличие только в возвращаемом типе — ошибка компиляции.
:::

:::task video "3. Static и не-static члены. Откуда к чему можно обращаться?"
{{t j2 7:25:20}}
??? Ответ
Статические принадлежат классу и доступны без объекта; нестатические — объекту. Из статического метода — только к статическим членам (нестатических без объекта не существует); из нестатического — к любым.
:::

:::task video "4. Модификаторы доступа"
{{t j2 7:26:08}}
??? Ответ
`public` — везде; `protected` — пакет + наследники; package-private (без модификатора) — внутри пакета; `private` — внутри класса. (В видео для `protected` упомянуты только наследники — он виден и всему пакету.)
:::

:::task video "5. Абстрактный класс vs интерфейс"
{{t j2 7:26:32}}
??? Ответ
Интерфейс — контракт/поведение, без состояния (только константы), множественная реализация; с Java 8 есть `default`/`static`, с Java 9 — `private` методы. Абстрактный класс — общая сущность родственных классов: поля, конструкторы, любая реализация; наследовать можно только один.
:::

## Коллекции

:::task video "6. Иерархия Collection Framework"
{{t j2 7:27:36}}
??? Ответ
`Iterable` → `Collection` → `List` (`ArrayList`, `LinkedList`), `Set` (`HashSet`, `LinkedHashSet`, `TreeSet`), `Queue`/`Deque` (`ArrayDeque`, `LinkedList`, `PriorityQueue`). Отдельно `Map`: `HashMap`, `LinkedHashMap`, `TreeMap`.
:::

:::task video "7. ArrayList vs LinkedList: устройство и выбор"
{{t j2 7:28:11}}
??? Ответ
`ArrayList` — динамический массив: O(1) доступ по индексу, вставка в середину O(n). `LinkedList` — двусвязный список: O(1) вставка/удаление на концах и через итератор, доступ по индексу O(n). По умолчанию — `ArrayList`; для очередей — `ArrayDeque`.
:::

:::task video "8. List vs Set"
{{t j2 7:28:45}}
??? Ответ
`List` — упорядочен, допускает дубликаты, доступ по индексу. `Set` — без дубликатов, без индексных методов.
:::

:::task video "9. equals и hashCode: зачем и какие правила?"
{{t j2 7:29:12}}
??? Ответ
Методы `Object`: сравнение по содержимому и числовое представление для хеш-коллекций. Переопределил `equals` — переопредели `hashCode`; равные объекты — равные хеши; равные хеши не гарантируют равенства.
:::

:::task video "10. Как устроен HashMap и как решаются коллизии?"
{{t j2 7:29:54}}
??? Ответ
Массив корзин (16 по умолчанию, расширение при заполнении 75 %). Индекс — по хешу ключа; занято — сравнение ключей `equals`: равны — замена значения, иначе коллизия — элемент в связный список корзины; при 8+ элементах в корзине и ёмкости ≥ 64 список превращается в красно-чёрное дерево.
:::

:::task video "11. Сложность вставки в начало: ArrayList и LinkedList"
{{t j2 7:30:55}}
??? Ответ
`ArrayList` — O(n) (сдвиг всех элементов), `LinkedList` — O(1).
:::

## Дженерики

:::task video "12. Что такое дженерики и wildcard?"
{{t j2 7:31:05}}
??? Ответ
Параметризованные типы: классы, интерфейсы, методы с типом-параметром; проверка типов при компиляции, стирание в рантайме. Wildcard `?` — неизвестный тип, ограничивается `? extends T` (читаем) и `? super T` (пишем) — PECS.
:::

## Многопоточность

:::task video "13. Как остановить поток? interrupt и join"
{{t j2 7:31:37}}
??? Ответ
Кооперативно через `interrupt()` (флаг + `InterruptedException` в ожидании); `stop()` с Java 20 не работает. `join()` — ждать завершения другого потока.
:::

:::task video "14. Способы синхронизации. Что такое монитор?"
{{t j2 7:32:32}}
??? Ответ
`synchronized`-метод (монитор `this` или `Class`) и `synchronized`-блок с явным монитором; также `Lock`, атомики, concurrent-коллекции.
:::

:::task video "15. Демоны, wait, notify/notifyAll"
{{t j2 7:33:04}}
??? Ответ
Демон завершается, когда закончились все основные потоки. `wait()` — ждать и отпустить монитор; `notify()` будит один ждущий поток, `notifyAll()` — все. Вызываются внутри `synchronized` по тому же объекту, `wait` — в цикле.
:::

:::task video "16. ExecutorService: зачем, submit vs execute, Runnable vs Callable"
{{t j2 7:33:40}}
??? Ответ
Пул переиспользуемых потоков с очередью задач. `execute(Runnable)` — без результата; `submit` возвращает `Future`. `Callable` возвращает значение и может бросать проверяемые исключения.
:::

:::task video "17. volatile"
{{t j2 7:34:35}}
??? Ответ
Видимость записи всем потокам и запрет переупорядочивания вокруг поля; не даёт атомарности `++`.
:::

## Stream API

:::task video "18. Что делает stream() и зачем стримы?"
{{t j2 7:35:02}}
??? Ответ
Превращает коллекцию в конвейер обработки: компактные фильтрация, преобразование, сортировка без промежуточных коллекций; ленивость; лёгкое распараллеливание `parallelStream()`.
:::

:::task video "19. Терминальные и промежуточные операции. Что делает map?"
{{t j2 7:35:43}}
??? Ответ
Промежуточные возвращают `Stream` и ленивы, их сколько угодно; терминальная одна, запускает конвейер. `map` преобразует каждый элемент, тип может меняться.
:::

## Ввод-вывод

:::task video "20. Сериализация: что это и какие условия?"
{{t j2 7:36:16}}
??? Ответ
Преобразование объекта в байты и обратно. Условия: `Serializable`/`Externalizable`; поля сериализуемы или `transient`; несериализуемый предок с доступным конструктором без параметров.
:::

:::task video "21. transient и буферизированные классы"
{{t j2 7:37:05}}
??? Ответ
`transient` исключает поле из сериализации. Буфер: `BufferedInputStream`, `BufferedOutputStream`, `BufferedReader`, `BufferedWriter`.
:::

## Что спросят дальше (не из видео)

:::task easy "String pool и сравнение строк"
Чем `==` отличается от `equals` для строк? Что такое пул строк?
??? Ответ
`==` сравнивает ссылки, `equals` — содержимое. Литералы хранятся в пуле строк и переиспользуются, поэтому `"a" == "a"` может быть `true`, но `new String("a") == "a"` — `false`. Строки сравнивают через `equals`.
:::

:::task medium "Records, var, switch-выражения"
Что из современной Java (17–25) вы используете?
??? Ответ
`record` для неизменяемых данных, `var`, текстовые блоки `"""`, switch-выражения и pattern matching (`instanceof` с переменной, `switch` по типам, record-паттерны), `sealed`-иерархии, виртуальные потоки, Sequenced Collections, `Stream.toList()`.
:::

:::task medium "Как устроена память JVM?"
Куча, стек и что где хранится.
??? Ответ
Стек потока — кадры вызовов, локальные примитивы и ссылки. Куча — объекты (общая для потоков, очищается GC, поколения young/old). Metaspace — метаданные классов. `StackOverflowError` — переполнение стека (глубокая рекурсия), `OutOfMemoryError` — нехватка кучи/метаспейса.
:::

:::task hard "Live-coding"
Разработайте потокобезопасный LRU-кеш на N элементов с методами `get` и `put` и объясните сложность операций.
??? Ответ
`LinkedHashMap` с `accessOrder = true` и `removeEldestEntry`, все методы под одной блокировкой (`synchronized` или `ReentrantLock`) — O(1). Для высокой конкуренции — готовые библиотеки (Caffeine). Обсудите, почему `ConcurrentHashMap` сам по себе не даёт порядка вытеснения.
:::
