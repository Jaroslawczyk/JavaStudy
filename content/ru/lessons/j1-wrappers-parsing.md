## Классы-обёртки

У каждого примитивного типа есть **ссылочный аналог** — класс-обёртка:

| Примитив | Обёртка |
|---|---|
| `byte` | `Byte` |
| `short` | `Short` |
| `int` | `Integer` |
| `long` | `Long` |
| `float` | `Float` |
| `double` | `Double` |
| `char` | `Character` |
| `boolean` | `Boolean` |

Зачем они нужны:

- **Коллекции хранят только объекты**: `ArrayList<int>` не скомпилируется, нужен `ArrayList<Integer>` (следующий урок).
- Обёртка может быть `null` — «значения нет» (например, необязательное поле в базе данных).
- Полезные статические методы и константы: `Integer.parseInt`, `Integer.MAX_VALUE`, `Character.isDigit`, `Double.compare`.

### Автоупаковка и распаковка

```java
Integer a = 5;        // автоупаковка (autoboxing): int → Integer
int b = a + 10;       // автораспаковка (unboxing): Integer → int
```

Компилятор сам вставляет `Integer.valueOf(5)` и `a.intValue()`. Это удобно, но **не бесплатно**: создаются объекты, тратится память. Поэтому правило из видео верное — **везде, где можно, используйте примитивы**.

## Строка → число

```java
String s1 = "1000";
String s2 = "2000";
System.out.println(s1 + s2);                 // 10002000 — склейка строк!

int n1 = Integer.parseInt(s1);
int n2 = Integer.parseInt(s2);
System.out.println(n1 + n2);                 // 3000

double d = Double.parseDouble("166.3");
long l = Long.parseLong("9000000000");
boolean b = Boolean.parseBoolean("false");   // false
```

:::warning "NumberFormatException"
`Integer.parseInt("12a")`, `Integer.parseInt("")` и `Double.parseDouble("166,3")` бросают `NumberFormatException` — программа упадёт. Обратите внимание: в Java дробная часть отделяется **точкой**, строку «166,3» нужно сначала исправить: `s.replace(',', '.')`.
:::

`Boolean.parseBoolean` возвращает `true` только для строки `"true"` (без учёта регистра: `"TRUE"` и `"True"` тоже дадут `true`), всё остальное — `false`. Для `char` метода `parse` нет: символ берут через `s.charAt(0)`.

Обратное преобразование — число в строку: `String.valueOf(42)`, `Integer.toString(42)` или `"" + 42`.

## substring — часть строки

```java
String s = "Это Игорь, он программист";
String name = s.substring(4, 9);   // "Игорь" — с индекса 4 включительно до 9 НЕ включительно
String tail = s.substring(4);      // "Игорь, он программист" — с 4 до конца
```

Правило «начало включительно, конец не включительно» действует почти везде в Java (`substring`, `subList`, `Arrays.copyOfRange`, `IntStream.range`). Удобно: длина результата = `end - start`.

## Что не рассказано в видео

:::outdated "new Integer(5) больше не используют"
В старом коде встречается `new Integer(5)`, `new Double(3.14)`. Эти конструкторы помечены устаревшими с Java 9, а с Java 16 — к удалению (`forRemoval`). Используйте `Integer.valueOf(5)` или просто автоупаковку `Integer x = 5;`.
:::

### Ловушка: сравнение обёрток через ==

```java
Integer a = 127, b = 127;
System.out.println(a == b);        // true  — значения от -128 до 127 кэшируются
Integer c = 128, d = 128;
System.out.println(c == d);        // false — разные объекты!
System.out.println(c.equals(d));   // true
```

Обёртки, как и строки, сравнивают через `equals`. Это популярный вопрос на собеседованиях («Integer cache»).

### Ловушка: распаковка null

```java
Integer count = null;
int x = count;        // NullPointerException при автораспаковке
```

### Поиск подстроки вместо «магических» индексов

Жёстко заданные индексы (`substring(4, 9)`) ломаются, как только меняется текст. Надёжнее искать позиции:

```java
int start = s.indexOf("Это ") + 4;
int end = s.indexOf(",", start);
String name = s.substring(start, end);
```

Или разбить строку: `s.split(" ")`, `s.split("\\. ")`. Для сложного разбора есть регулярные выражения — статья [Regular Expressions](#/extra/regex).
