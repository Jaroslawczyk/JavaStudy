## Объявление метода

```text
тип_возвращаемого_значения имяМетода(тип1 параметр1, тип2 параметр2) {
    тело метода
}
```

- **Тип возвращаемого значения** — любой: примитив, `String`, ваш класс. Если метод ничего не возвращает — `void`.
- Если тип не `void`, метод **обязан** завершаться `return значение;` с подходящим типом.
- Без параметров — пустые скобки `()`.

```java
public class Box {
    double width;
    double height;
    double length;

    void showVolume() {                       // ничего не возвращает — печатает
        System.out.println("Объём: " + volume());
    }

    double volume() {                         // возвращает значение
        return width * height * length;
    }

    void setDimens(double width, double height, double length) {
        this.width = width;                   // this.width — поле, width — параметр
        this.height = height;
        this.length = length;
    }
}
```

```java
Box box = new Box();
box.setDimens(15, 15, 15);
System.out.println(box.volume());   // 3375.0
box.showVolume();                   // Объём: 3375.0
```

## Как метод «знает», чей это объём

Внутри класса к полям обращаются без точки: `width * height * length`. Подразумевается поле **того объекта, у которого вызвали метод**: `box1.volume()` считает объём `box1`, `box2.volume()` — объём `box2`.

## Ключевое слово this

`this` — ссылка на текущий объект. Нужна, когда имя параметра совпадает с именем поля:

```java
void setDimens(double width, double height, double length) {
    width = width;          // ОШИБКА ЛОГИКИ: параметр присваивается сам себе
    this.width = width;     // правильно: полю объекта — значение параметра
}
```

Давать параметрам такие же имена, как полям, — нормальная практика: имена понятные, а <kbd>Ctrl+P</kbd> в IDEA подскажет порядок аргументов.

## Параметры и аргументы

- **Параметр** — переменная в объявлении метода: `int i` в `square(int i)`.
- **Аргумент** — конкретное значение при вызове: `80` в `square(80)`.

```java
int square(int i) {
    return i * i;
}
// test.square(80) → 6400, test.square(15) → 225
```

Методы с параметрами делают код универсальным: вместо `square10()`, `square11()`… — один `square(int i)`.

## Что не рассказано в видео

### Java передаёт аргументы по значению

В метод всегда передаётся **копия** значения. Для примитивов — копия числа, для объектов — копия **ссылки**:

```java
void reset(int x) { x = 0; }                 // снаружи ничего не изменится
void resetBox(Box b) { b.width = 0; }        // изменится объект — ссылка указывает на него
void replaceBox(Box b) { b = new Box(); }    // снаружи ничего не изменится — заменили копию ссылки
```

Это частый вопрос на собеседованиях: «В Java передача по ссылке или по значению?» Ответ: **всегда по значению** (подробно — в статье [Pass by Value](#/extra/pass-by-value)).

### Как называть методы

- Глагол или глагольная фраза: `calculateTotal()`, `printReport()`, `isEmpty()`, `hasNext()`.
- Методы, возвращающие `boolean`, начинаются с `is`/`has`/`can`.
- Один метод — одна задача. Если в имени хочется написать «And» — метод стоит разделить.

### Метод без вывода лучше метода с выводом

Автор переделал `showVolume()` в `volume()`, который возвращает число. Это важный принцип: метод, который **вычисляет и возвращает**, можно использовать где угодно (в другом расчёте, в тесте, в веб-ответе), а метод, который **печатает**, — только в консоли.

### Ранний return

```java
String grade(int score) {
    if (score < 0 || score > 100) {
        return "ошибка";       // сразу выходим — меньше вложенности
    }
    if (score >= 90) {
        return "отлично";
    }
    return "хорошо";
}
```

`return` в `void`-методе тоже допустим (без значения) — для досрочного выхода.

### Переменное число аргументов (varargs)

```java
int sum(int... numbers) {          // внутри numbers — это int[]
    int total = 0;
    for (int n : numbers) total += n;
    return total;
}
// sum(1, 2), sum(1, 2, 3, 4), sum()
```

Так устроены `String.format(...)` и `printf(...)`.
