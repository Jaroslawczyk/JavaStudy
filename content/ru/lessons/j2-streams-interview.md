## Вопросы

:::task video "1. Что такое функциональный интерфейс?"
{{t j2 5:13:32}}
??? Ответ
Интерфейс ровно с одним абстрактным методом (`default`/`static` не считаются). Только его можно реализовать лямбдой или ссылкой на метод. Помечается `@FunctionalInterface`. Примеры: `Runnable`, `Comparator`, `Predicate`, `Function`.
:::

:::task video "2. Что делает метод stream()?"
{{t j2 5:13:42}}
??? Ответ
Создаёт из коллекции последовательный стрим — поток элементов для конвейерной обработки. Сама коллекция не меняется.
:::

:::task video "3. Зачем преобразовывать коллекции в стримы?"
{{t j2 5:13:54}}
??? Ответ
Компактно и декларативно описать фильтрацию, преобразование, сортировку, группировку без промежуточных коллекций; ленивое выполнение с остановкой (`limit`, `findFirst`); простое распараллеливание через `parallelStream()`.
:::

:::task video "4. Какие способы создания стримов вы знаете?"
{{t j2 5:14:28}}
??? Ответ
`collection.stream()/parallelStream()`, `Arrays.stream(array)`, `Stream.of(...)`, `Stream.iterate`, `Stream.generate`, `IntStream.range`, `Files.lines(path)`, `String.chars()`, `Stream.empty()`, `Stream.ofNullable` (9).
:::

:::task video "5. Чем терминальная операция отличается от промежуточной?"
{{t j2 5:14:42}}
??? Ответ
Промежуточная возвращает `Stream` и ленива; их в цепочке сколько угодно. Терминальная возвращает результат (или `void`), запускает весь конвейер и закрывает стрим; она одна и в конце.
:::

:::task video "6. Примеры терминальных и промежуточных операций"
{{t j2 5:15:19}}
??? Ответ
Терминальные: `collect`, `toList`, `count`, `min`/`max`, `forEach`, `reduce`, `anyMatch`, `findFirst`. Промежуточные: `filter`, `map`, `flatMap`, `sorted`, `distinct`, `limit`, `skip`, `peek`.
:::

:::task video "7. Что делает map?"
{{t j2 5:15:43}}
??? Ответ
Применяет функцию к каждому элементу; тип результата может отличаться от исходного (`Stream<User>` → `Stream<String>`).
:::

:::task video "8. Optional — что это и как связан со стримами?"
{{t j2 5:15:55}}
??? Ответ
Контейнер для значения, которого может не быть. Операции `findFirst`, `findAny`, `min`, `max`, `reduce` без начального значения возвращают `Optional`, потому что стрим может быть пустым. Значение достают через `orElse…`, `ifPresent…`, `map`.
:::

:::task video "9. Как работает filter?"
{{t j2 5:16:33}}
??? Ответ
Принимает `Predicate` и пропускает дальше только элементы, для которых он вернул `true`.
:::

:::task video "10. Как sorted() сортирует объекты нашего класса?"
{{t j2 5:16:56}}
??? Ответ
Без аргументов — по естественному порядку: класс должен реализовать `Comparable`, иначе `ClassCastException`. Либо передать `Comparator`: `sorted(Comparator.comparing(User::name))`.
:::

## Дополнительные вопросы (не из видео)

:::task easy "map vs flatMap"
Чем отличаются?
??? Ответ
`map` — один элемент в один. `flatMap` — один элемент в стрим элементов, которые «расплющиваются» в общий стрим: `List<List<T>>` → `Stream<T>`.
:::

:::task medium "Почему стрим нельзя использовать повторно?"
И что будет, если попробовать?
??? Ответ
Стрим — одноразовое описание вычисления над источником; после терминальной операции он закрыт, повторный вызов бросает `IllegalStateException`. Нужен новый стрим из источника.
:::

:::task medium "Collectors.toList() vs Stream.toList()"
В чём разница?
??? Ответ
`Stream.toList()` (Java 16) возвращает неизменяемый список и допускает `null`-элементы. `Collectors.toList()` возвращает изменяемый список (на практике `ArrayList`, но без гарантии в спецификации).
:::

:::task hard "Live-coding: группировка"
Дан `List<Order(String customer, double amount)>`. Одним выражением получите `Map<String, Double>` — сумму заказов по клиентам, отсортированную по убыванию суммы.
??? Ответ
`orders.stream().collect(groupingBy(Order::customer, summingDouble(Order::amount))).entrySet().stream().sorted(Map.Entry.<String, Double>comparingByValue().reversed()).collect(toMap(Map.Entry::getKey, Map.Entry::getValue, (a, b) -> a, LinkedHashMap::new))` — `LinkedHashMap` сохраняет порядок сортировки.
:::
