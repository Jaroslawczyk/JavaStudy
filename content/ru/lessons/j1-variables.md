## Что такое переменная

**Переменная** — именованная ячейка памяти, в которой хранится значение. Автор сравнивает её с футляром для зубной щётки: футляр (переменная) может быть пустым или содержать щётку (значение), но гитару в него положить нельзя — тип строго определён.

```java
int number;        // объявление: тип + имя
number = 5;        // присваивание
int count = 10;    // объявление с инициализацией
```

- Сначала пишется **тип** (`int`), затем **имя**, затем `;`.
- Знак `=` — это **присваивание**, а не «равно» из математики: «положить значение справа в переменную слева».
- Переменную можно использовать только после того, как ей присвоено значение — иначе ошибка компиляции `variable might not have been initialized`.

## Тип int и арифметика

`int` хранит целые числа примерно от −2,1 млрд до 2,1 млрд.

```java
int a = 5;
int b = 7;
int c = a + b;
System.out.println("a + b = " + c);   // a + b = 12

c = c + 5;      // 17
c = c * 10;     // 170
```

| Оператор | Действие | Пример | Результат |
|---|---|---|---|
| `+` | сложение | `7 + 3` | `10` |
| `-` | вычитание | `7 - 3` | `4` |
| `*` | умножение | `7 * 3` | `21` |
| `/` | деление (для `int` — **целочисленное**) | `10 / 3` | `3` |
| `%` | остаток от деления | `10 % 3` | `1` |

:::warning "Целочисленное деление"
Если оба операнда — целые числа, результат тоже целый, дробная часть **отбрасывается** (не округляется!): `10 / 3 == 3`, `-7 / 2 == -3`. Чтобы получить дробный результат, хотя бы один операнд должен быть дробным: `10 / 3.0 == 3.333…` (об этом — в уроке о дробных типах).
:::

### Сокращённые операторы присваивания

| Полная запись | Сокращённая |
|---|---|
| `c = c + 5` | `c += 5` |
| `c = c - 5` | `c -= 5` |
| `c = c * 10` | `c *= 10` |
| `c = c / 2` | `c /= 2` |
| `c = c % 3` | `c %= 3` |

### Конкатенация строк

Оператор `+` со строкой «склеивает» значения: `"c = " + c` → `"c = 170"`. Осторожно с порядком:

```java
int a = 5, b = 7;
System.out.println("Сумма: " + a + b);    // Сумма: 57  — склеились как строки!
System.out.println("Сумма: " + (a + b));  // Сумма: 12  — скобки сначала считают число
System.out.println(a + b + " — сумма");   // 12 — сумма  — слева направо: сначала числа
```

## Разбор задачи из видео: дни → годы, месяцы, дни

```java
public class Days {
    public static void main(String[] args) {
        int days = 5000;
        int years = days / 365;
        int months = (days % 365) / 31;
        int leftDays = days - years * 365 - months * 31;

        System.out.println("Всего дней: " + days);
        System.out.println("Лет: " + years);
        System.out.println("Месяцев: " + months);
        System.out.println("Дней: " + leftDays);
    }
}
```

Результат: 13 лет, 8 месяцев, 7 дней. Обратите внимание на приём «деление + остаток»: `/` даёт количество целых частей, `%` — то, что осталось. Этот приём понадобится в домашнем задании.

:::note
Задача учебная: в ней год — всегда 365 дней, а месяц — 31 день. Для реальных дат в Java есть пакет `java.time` (`Period`, `Duration`, `LocalDate`) — он учитывает високосные годы и разную длину месяцев. Его мы разберём в отдельной статье [Date and Time](#/extra/date-time).
:::

## Что не рассказано в видео

### Правила имён переменных

- Можно: буквы, цифры, `_` и `$`; **нельзя** начинать с цифры: `2count` — ошибка.
- Нельзя использовать ключевые слова: `int class = 5;` — ошибка.
- Стиль: `lowerCamelCase` — `totalPrice`, `daysInMonth`. Имя должно объяснять смысл: `d` хуже, чем `days`.

### Константы и `final`

```java
final int DAYS_IN_YEAR = 365;
DAYS_IN_YEAR = 366;   // ошибка компиляции: переменная final
```

`final` запрещает повторное присваивание. Такие «магические числа» лучше выносить в константы с понятным именем.

### Ключевое слово var (Java 10+)

```java
var days = 5000;      // компилятор сам выводит тип int
```

`var` — не «динамический тип»: тип определяется один раз при компиляции и не меняется. Удобно для длинных типов, но для `int` новичкам лучше писать тип явно.

### Подчёркивания в числах (Java 7+)

```java
int days = 5_000;
int million = 1_000_000;
```

В видео «5.000» — это просто устная запись. В коде Java точка разделяет **дробную** часть, а разряды разделяют знаком `_`.

### Деление на ноль

```java
int x = 10 / 0;   // ArithmeticException: / by zero — программа упадёт
```

### Ввод с клавиатуры

В видео значения задаются прямо в коде. Чтобы программа спрашивала их у пользователя, используется `Scanner`:

```java
import java.util.Scanner;

public class InputDemo {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        System.out.print("Введите количество секунд: ");
        int seconds = scanner.nextInt();
        System.out.println("Вы ввели: " + seconds);
    }
}
```

С Java 25 можно проще: `int seconds = Integer.parseInt(IO.readln("Введите секунды: "));`

```java
int total = 100000;
```

:::task hard "Сдача монетами"
Покупатель должен получить сдачу `n` копеек/грошей (например, 289). Есть монеты 50, 20, 10, 5, 2, 1. Выведите, сколько монет каждого номинала выдать, чтобы монет было как можно меньше. Затем добавьте ввод `n` с клавиатуры через `Scanner`.
??? Подсказка
Это «жадный» алгоритм: сначала максимально большими монетами, остаток — следующими.
```java
int coins50 = n / 50;  n %= 50;
int coins20 = n / 20;  n %= 20;
// ...
```
Для 289: 5×50, 1×20, 1×10, 1×5, 2×2, 0×1.
:::
