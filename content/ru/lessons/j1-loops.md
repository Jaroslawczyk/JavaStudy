**Цикл** — повторение действий, пока выполняется условие. Вместо тысячи строк `println` — три строки цикла. Разбираем `while`, `do-while`, `for`, операторы `++`/`--` и `break`.

## Инкремент и декремент

```java
int a = 10;
a = a + 1;   // 11
a += 1;      // 12
a++;         // 13 — инкремент: +1
a--;         // 12 — декремент: −1
```

## Цикл while

```java
int i = 1;
while (i <= 1000) {
    System.out.println(i);
    i++;
}
```

Порядок: **проверить условие → если true, выполнить тело → снова проверить**. Как только условие стало `false`, цикл завершается и программа идёт дальше.

:::warning "Бесконечный цикл"
Если забыть `i++`, условие `i <= 1000` будет истинно вечно, и программа никогда не остановится. В IDEA остановите её красной кнопкой ■ Stop (<kbd>Ctrl+F2</kbd>).
:::

### break — досрочный выход

```java
int i = 1;
while (i <= 1000) {
    if (i == 5) {
        break;          // выйти из цикла немедленно
    }
    System.out.println(i);   // 1 2 3 4
    i++;
}
```

## Цикл do-while

Сначала выполняет тело, потом проверяет условие — значит, тело выполнится **хотя бы один раз**:

```java
int a = 0;
do {
    System.out.println("Привет");   // выведется один раз
} while (a > 0);                    // ; после while обязательна
```

Применяется редко — например, «спрашивать ввод, пока пользователь не введёт корректное значение».

## Цикл for

Лучше всего подходит, когда **известно количество повторений**:

```java
for (int i = 0; i < 100; i++) {
    System.out.println(i);   // 0 … 99
}
```

В скобках три части через `;`:

1. **Инициализация** — выполняется один раз: `int i = 0`
2. **Условие** — проверяется перед каждым шагом: `i < 100`
3. **Обновление** — выполняется после каждого шага: `i++`

```java
// Числа от 1000 до 0, которые делятся на 3
for (int i = 1000; i >= 0; i--) {
    if (i % 3 == 0) {
        System.out.println(i);
    }
}
```

Четвёртый вид цикла — **for-each** — разберём в уроке о массивах.

## Разбор задачи: среднее от 0 до 100

```java
int sum = 0;
int count = 1;
while (count <= 100) {
    sum += count;
    count++;
}
float result = sum / (float) count;   // приведение — иначе деление целочисленное
System.out.println(result);           // 50.0
```

:::note "Тонкость в решении из видео"
Числа от 0 до 100 — это **101** число, их сумма 5050, и среднее 5050 / 101 = 50. Код в видео даёт верный ответ, потому что после цикла `count` равен 101. Но объяснение «делим на 100» неточно: если бы задача была про числа от 1 до 100, правильный ответ — 5050 / 100 = **50.5**. Всегда проверяйте, чему равен счётчик *после* цикла!
:::

## Что не рассказано в видео

### continue — пропустить шаг

```java
for (int i = 1; i <= 10; i++) {
    if (i % 2 == 0) {
        continue;            // перейти сразу к следующей итерации
    }
    System.out.println(i);   // 1 3 5 7 9
}
```

### Шаг цикла — не обязательно 1

Вместо проверки остатка часто проще сразу шагать нужным шагом:

```java
for (int i = 1000; i >= 0; i -= 2) {   // только чётные — без if
    System.out.println(i);
}
```

### i++ и ++i

```java
int a = 5;
int b = a++;   // b = 5, a = 6 — постфикс: сначала отдать значение, потом увеличить
int c = ++a;   // c = 7, a = 7 — префикс: сначала увеличить, потом отдать
```

В цикле `for` разницы нет. Внутри выражений разница есть — лучше не смешивать `++` со сложными выражениями.

### Область видимости счётчика

Переменная `i`, объявленная в `for (int i = …)`, существует только внутри цикла. После цикла её нет — это защищает от случайного использования.

### Вложенные циклы и метки

```java
for (int row = 1; row <= 9; row++) {
    for (int col = 1; col <= 9; col++) {
        System.out.print(row * col + "\t");
    }
    System.out.println();
}
```

Чтобы выйти сразу из двух циклов, используют метку: `outer: for (…) { for (…) { break outer; } }`. Но чаще лучше вынести циклы в метод и сделать `return`.

### Какой цикл выбирать

| Ситуация | Цикл |
|---|---|
| Известно число повторений / проход по индексам | `for` |
| Повторять, пока условие (неизвестно, сколько раз) | `while` |
| Тело должно выполниться минимум один раз | `do-while` |
| Перебрать все элементы массива/коллекции | `for-each` (следующий урок) |
| Обработка коллекций в функциональном стиле | Stream API (часть 2 курса) |

:::task hard "Простые числа"
Выведите все простые числа от 2 до 1000 и их количество (должно быть 168). Затем оптимизируйте: проверяйте делители только до `√n`, а чётные числа больше 2 не проверяйте вовсе.
??? Подсказка

:::
