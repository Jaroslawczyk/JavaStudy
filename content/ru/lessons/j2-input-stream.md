## InputStream и FileInputStream

«Поток» здесь — не `Thread` и не `Stream` из Stream API, а последовательность байтов, которую читают по порядку.

```java
try (InputStream in = new FileInputStream("file1.txt")) {
    int b = in.read();                  // 0..255, или -1 — данные кончились
    while (b != -1) {
        System.out.print((char) b);     // для латиницы байт = символ
        b = in.read();
    }
} catch (IOException e) {
    e.printStackTrace();
}
```

Почему `read()` возвращает `int`, а не `byte`? Байт в Java знаковый (−128…127), и тогда нельзя было бы отличить реальный байт `-1` (`0xFF`) от «конца файла». Поэтому значение возвращается в диапазоне 0–255, а −1 — особый сигнал.

## Закрытие ресурсов

Открытый поток держит ресурс операционной системы (дескриптор файла). Незакрытые потоки — утечка: однажды ОС откажет в открытии новых файлов, а в Windows открытый файл нельзя удалить.

До Java 7 писали так:

```java
InputStream in = null;
try {
    in = new FileInputStream(file);
    // чтение…
} catch (IOException e) {
    e.printStackTrace();
} finally {
    if (in != null) {
        try { in.close(); } catch (IOException e) { e.printStackTrace(); }
    }
}
```

## try-with-resources (Java 7+)

```java
try (InputStream in = new FileInputStream(file);
     OutputStream out = new FileOutputStream(copy)) {   // несколько ресурсов через ;
    in.transferTo(out);                                  // Java 9: копирование одной строкой
}
```

- Ресурсы закрываются **автоматически** при выходе из блока — и при нормальном завершении, и при исключении.
- Закрываются **в обратном порядке** объявления.
- Ресурс должен реализовать **`AutoCloseable`** (видео говорит `Closeable` — это его наследник для I/O; подходят оба).
- Если исключение возникло и в теле, и в `close()`, второе не теряется — оно добавляется как **suppressed**: `e.getSuppressed()`.
- С Java 9 можно указать уже объявленную effectively final переменную: `try (in) { … }`.

:::interview "Вопрос с собеседования"
**Что такое try-with-resources и зачем он нужен?** — Конструкция, в которой ресурсы, объявленные в скобках после `try`, автоматически закрываются вызовом `close()` при выходе из блока. Работает с любым `AutoCloseable`. Заменяет громоздкий `finally` с проверкой на `null`, корректно обрабатывает исключения при закрытии (suppressed).
:::

## Что не рассказано в видео

- **`readAllBytes()`** (Java 9) — прочитать весь поток в массив; **`readNBytes(n)`** (11), **`transferTo(out)`** (9).
- **Иерархия:** `InputStream` ← `FileInputStream`, `ByteArrayInputStream`, `BufferedInputStream`, `ObjectInputStream`, `System.in`… Обёртки (декораторы) добавляют возможности базовому потоку — это паттерн **Decorator**.
- **Современно для текстовых файлов:** `Files.readString(path)` или `Files.readAllLines(path)` — открытие, чтение и закрытие в одной строке.
