## float и double

| Тип | Размер | Точность | Литерал |
|---|---|---|---|
| `float` | 4 байта | ~7 значащих цифр | `3.14f` (суффикс `f` обязателен) |
| `double` | 8 байт | ~15–16 значащих цифр | `3.14` (по умолчанию все дробные литералы — `double`) |

Разделитель целой и дробной части в коде — **точка**, не запятая.

```java
double r = 10.8;
double pi = 3.14;
double s = pi * r * r;
System.out.println("Площадь круга = " + s);   // 366.2496...
```

:::outdated "float или double?"
В видео совет: «если нужна точность в 1–2 знака — используйте `float`». Сегодня общепринятая практика другая: **по умолчанию всегда `double`**. Экономия 4 байт почти никогда не важна, а точность `float` легко «съедается» уже в простых вычислениях. `float` используют в графике, играх и огромных массивах чисел (машинное обучение).
:::

:::tip "Используйте Math.PI"
Вместо `3.14` пишите `Math.PI` (3.141592653589793): точнее и понятнее.
:::

### Почему 0.1 + 0.2 ≠ 0.3

```java
System.out.println(0.1 + 0.2);         // 0.30000000000000004
System.out.println(0.1 + 0.2 == 0.3);  // false
```

Дробные числа хранятся в **двоичном** виде (стандарт IEEE 754), а 0.1 в двоичной системе — бесконечная дробь, как 1/3 в десятичной. Отсюда правила:

- **Деньги никогда не храните в `double`/`float`** — используйте `BigDecimal` или целые числа в копейках/грошах (`long`).
- Дробные числа не сравнивают через `==`; сравнивают с допуском: `Math.abs(a - b) < 1e-9`.

### Деление на ноль у дробных

```java
System.out.println(10.0 / 0);    // Infinity
System.out.println(0.0 / 0);     // NaN (Not a Number)
```

В отличие от `int`, исключения нет.

## char — символ

`char` хранит **один символ** в одинарных кавычках. Внутри это число — код символа в таблице **Unicode** (UTF-16), поэтому `char` формально целочисленный тип (0 … 65 535).

```java
char ch1 = 89;      // код символа 'Y'
char ch2 = 'Y';     // сам символ
System.out.println(ch1 + " " + ch2);   // Y Y
ch1 += 1;
System.out.println(ch1);               // Z
```

:::note "ASCII и Unicode"
В видео говорится о таблице ASCII. Точнее: Java использует **Unicode**, а первые 128 кодов Unicode совпадают с ASCII (латиница, цифры, знаки). Кириллица и польские буквы тоже есть: `'Ж'` = 1046, `'ł'` = 322. Эмодзи не помещаются в один `char` — для них нужна пара `char` (суррогатная пара).
:::

Полезные методы класса `Character`: `Character.isDigit(c)`, `Character.isLetter(c)`, `Character.toUpperCase(c)`.

## boolean — логический тип

`boolean` хранит только `true` или `false`. Именно это значение возвращают операции сравнения:

```java
int temp = 26;
boolean isHot = temp > 25;   // true

if (isHot) {
    System.out.println("Кондиционер включён");
}
if (!isHot) {                // ! — «НЕ»
    System.out.println("Кондиционер выключен");
}
```

### Операторы сравнения

`<`, `<=`, `>`, `>=`, `==` (равно), `!=` (не равно).

:::warning "= и =="
`=` — присваивание, `==` — сравнение. `if (temp = 25)` — ошибка компиляции (в Java, в отличие от C, не скомпилируется: результат `int`, а не `boolean`). Но `if (isHot = true)` скомпилируется и всегда будет истинным — опасная опечатка. Поэтому `boolean` проверяют просто `if (isHot)`, без `== true`.
:::

### Логические операторы

| Оператор | Название | Результат `true`, если… |
|---|---|---|
| `&&` | И (AND) | оба условия истинны |
| `\|\|` | ИЛИ (OR) | хотя бы одно истинно |
| `!` | НЕ (NOT) | условие ложно |
| `^` | исключающее ИЛИ (XOR) | ровно одно истинно |

```java
int time = 24;
boolean late = time >= 23;
if (!isHot || late) {
    System.out.println("Кондиционер выключен");
}
```

## Разбор задачи «спать, гулять или читать»

Без `else`, все условия — в отдельных переменных:

```java
int time = 19;
boolean isGoodWeather = true;
boolean late = time >= 23 || time <= 5;

if (late) {
    System.out.println("Спать");
}
if (!late && isGoodWeather) {
    System.out.println("Гулять");
}
if (!late && !isGoodWeather) {
    System.out.println("Читать книгу");
}
```

## Что не рассказано в видео

### Короткое замыкание (short-circuit)

`&&` и `||` вычисляют правую часть, **только если нужно**: в `a && b` при `a == false` выражение `b` не проверяется. Это позволяет писать безопасно: `if (count != 0 && sum / count > 10)` — деления на ноль не будет. Операторы `&` и `|` для `boolean` вычисляют обе части всегда — используются редко.

### Приоритет операторов

`!` → арифметика → сравнения → `==`/`!=` → `&&` → `||` → `?:` → присваивания. Если сомневаетесь — ставьте скобки: `(a && b) || c` читается однозначно.

### Приведение дробных к целым

```java
double d = 9.99;
int i = (int) d;                 // 9 — дробная часть отбрасывается
long rounded = Math.round(d);    // 10 — математическое округление
double f = Math.floor(-2.5);     // -3.0 — вниз
double c = Math.ceil(2.1);       // 3.0 — вверх
```

### Полезные методы Math

`Math.sqrt`, `Math.pow(2, 10)`, `Math.abs`, `Math.max/min`, `Math.round`, `Math.hypot(a, b)` — гипотенуза одной функцией (но в домашнем задании сначала сделайте через `sqrt`!).
