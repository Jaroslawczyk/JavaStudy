До сих пор программы выполнялись строка за строкой. Условный оператор `if` позволяет выполнять код **только при определённом условии** — например, включать кондиционер, если в комнате жарко.

## Синтаксис

```java
if (условие) {
    // выполняется, если условие истинно (true)
} else if (другоеУсловие) {
    // выполняется, если первое ложно, а это истинно
} else {
    // выполняется, если все условия ложны
}
```

**Условие** — выражение, результат которого `true` (истина) или `false` (ложь). Например `temp > 25`. Подробно логический тип `boolean` разберём через урок.

## Разбор примера из видео

```java
public class Temperature {
    public static void main(String[] args) {
        int temp = 23;

        if (temp > 25) {
            System.out.println("Кондиционер включён");
        } else if (temp < 22) {
            System.out.println("Кондиционер выключен");
        } else {
            System.out.println("Кондиционер ничего не делает");
        }
    }
}
```

| `temp` | Что проверяется | Вывод |
|---|---|---|
| 30 | `30 > 25` → true | Кондиционер включён |
| 23 | `23 > 25` → false, `23 < 22` → false | Кондиционер ничего не делает |
| 21 | `21 > 25` → false, `21 < 22` → true | Кондиционер выключен |

Важно: из цепочки `if / else if / else` выполняется **ровно одна ветка** — первая, чьё условие истинно. Остальные проверки уже не делаются.

## Операторы сравнения

| Оператор | Значение |
|---|---|
| `>` / `<` | больше / меньше |
| `>=` / `<=` | больше или равно / меньше или равно |
| `==` | равно (два знака!) |
| `!=` | не равно |

## Что не рассказано в видео

### Всегда ставьте фигурные скобки

Если в ветке одна инструкция, скобки формально можно не писать — но это частый источник багов:

```java
if (temp > 25)
    System.out.println("Включаем");
    System.out.println("Охлаждаем");   // выполнится ВСЕГДА — отступ обманывает!
```

Правило большинства команд (и Google Java Style): **скобки всегда**.

### Вложенные условия

```java
if (temp > 25) {
    if (isNight) {
        System.out.println("Тихий режим");
    } else {
        System.out.println("Максимальное охлаждение");
    }
}
```

Глубокая вложенность читается плохо: лучше объединять условия логическими операторами `&&` и `||` (урок о `boolean`) или выносить проверки в методы.

### Тернарный оператор

Короткая форма `if-else`, которая **возвращает значение**:

```java
String status = temp > 25 ? "жарко" : "нормально";
```

Читается так: «если `temp > 25`, то `"жарко"`, иначе `"нормально"`». Используйте для простых случаев, без вложенных тернарных операторов.

### Оператор switch

Когда одна переменная сравнивается со многими значениями, удобнее `switch` — он разобран в уроке [Строки и switch](#/lessons/j1-strings-switch).

### Границы диапазонов

В домашнем задании легко ошибиться на границах: «от 300 до 500» — включая 300? 500? Всегда решайте это явно и проверяйте программу на **граничных значениях**: 99, 100, 299, 300, 500, 501.

:::task hard "Квадратное уравнение"
Даны коэффициенты `a`, `b`, `c` уравнения `ax² + bx + c = 0` (целые числа). Выведите количество корней и сами корни. Учтите случай `a == 0` (уравнение становится линейным) и случай, когда и `a`, и `b` равны нулю.
??? Подсказка
Дискриминант `d = b*b - 4*a*c`. Если `d > 0` — два корня `(-b ± Math.sqrt(d)) / (2.0 * a)`, если `d == 0` — один, если `d < 0` — действительных корней нет. Обратите внимание на `2.0` — иначе деление будет целочисленным.
:::
