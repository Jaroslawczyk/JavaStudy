## Объект в качестве параметра

```java
public class Box {
    private double width, height, length;

    public Box(double width, double height, double length) {
        this.width = width;
        this.height = height;
        this.length = length;
    }

    public double volume() {
        return width * height * length;
    }

    /** 1 — эта коробка больше, -1 — меньше, 0 — равны по объёму */
    public int compare(Box box) {
        double thisVolume = volume();
        double boxVolume = box.volume();
        if (thisVolume > boxVolume) {
            return 1;
        } else if (thisVolume < boxVolume) {
            return -1;
        }
        return 0;
    }
}
```

**Вызывающий объект** — тот, у которого вызвали метод (`box1` в `box1.compare(box2)`), он доступен как `this`. Переданный объект — параметр `box`.

```java
int result = box1.compare(box2);
switch (result) {
    case -1 -> System.out.println("Наша коробка меньше");
    case 0  -> System.out.println("Коробки равны");
    case 1  -> System.out.println("Наша коробка больше");
}
```

Соглашение «отрицательное / 0 / положительное» — стандарт Java: так работает `compareTo` у строк, чисел и всех объектов, реализующих интерфейс `Comparable`. Позже вы будете реализовывать его, чтобы сортировать свои объекты.

:::tip "Не изобретайте сравнение чисел"
Для сравнения чисел есть готовые методы: `return Double.compare(volume(), box.volume());` — одна строка вместо трёх `if`, и корректно обрабатывает особые значения вроде `NaN`.
:::

## Копирующий конструктор

```java
public Box(Box other) {
    this.width = other.width;     // внутри класса доступны private-поля другого объекта того же класса
    this.height = other.height;
    this.length = other.length;
}
```

```java
Box box1 = new Box(10, 10, 10);
Box box2 = new Box(box1);          // НОВАЯ коробка с теми же размерами
System.out.println(box1 == box2);  // false — разные объекты
```

Изменение `box1` больше не влияет на `box2` — в отличие от `Box box2 = box1;`.

## Метод, возвращающий объект

```java
public Box increase(int i) {
    return new Box(width * i, height * i, length * i);
}
```

```java
Box box1 = new Box(10, 10, 10);
Box box2 = box1.increase(2);
System.out.println(box1.volume());   // 1000.0
System.out.println(box2.volume());   // 8000.0 — каждое измерение ×2, объём ×8
```

Метод не меняет вызывающий объект, а возвращает **новый** — так устроены `String.toUpperCase()`, `BigDecimal.add()`, `LocalDate.plusDays()`. Это основа неизменяемых (immutable) объектов.

## Что не рассказано в видео

### Один return или несколько?

Автор показывает два стиля: несколько `return` (ранний выход) и одна переменная `result` с единственным `return` в конце. Современные стандарты (Google Java Style, большинство команд) **допускают несколько return** — так код короче и нет «лишних» состояний. Главное — единый стиль в проекте.

### Копирование: поверхностное и глубокое

Если поле само является объектом (например, у коробки есть поле `Color color`), копирующий конструктор, который пишет `this.color = other.color`, создаст **поверхностную** копию: обе коробки будут ссылаться на один объект цвета. Для **глубокой** копии нужно скопировать и вложенный объект: `this.color = new Color(other.color)`.

Метод `clone()` из класса `Object` для этого использовать не рекомендуется (его считают неудачным API) — копирующий конструктор или статический метод `copyOf` надёжнее.

### null в параметре

Если передать `box1.compare(null)`, метод упадёт с `NullPointerException` на `box.volume()`. В публичных методах параметры часто проверяют сразу: `Objects.requireNonNull(box, "box must not be null");`.
