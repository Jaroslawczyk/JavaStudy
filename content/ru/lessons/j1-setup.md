## Что такое Java и где её используют

**Java** — объектно-ориентированный язык общего назначения со строгой статической типизацией. Главный принцип — *«написано однажды — работает везде»* (Write Once, Run Anywhere): исходный код компилируется не в машинные команды конкретного процессора, а в **байт-код**, который исполняет виртуальная машина **JVM** на любой ОС.

Где Java используется сегодня:

- **Backend**: банки, финтех, страхование, e-commerce, госсектор (Spring Boot, Quarkus, Micronaut);
- **Big Data и стриминг**: Apache Kafka, Spark, Flink, Hadoop написаны на Java/Scala и работают на JVM;
- **Android**: исторически на Java, сейчас основной язык — Kotlin, но он тоже работает на JVM-технологиях и совместим с Java;
- **Enterprise-системы**, корпоративные интеграции, высоконагруженные сервисы;
- **Инструменты разработчика**: IntelliJ IDEA, Gradle, Maven, Jenkins написаны на Java.

## JDK, JRE и JVM — в чём разница

| Аббревиатура | Расшифровка | Что это |
|---|---|---|
| **JVM** | Java Virtual Machine | Виртуальная машина: исполняет байт-код, управляет памятью (сборщик мусора), JIT-компилирует «горячий» код в машинный |
| **JRE** | Java Runtime Environment | JVM + стандартные библиотеки — то, что нужно для *запуска* программ |
| **JDK** | Java Development Kit | JRE + инструменты разработчика: компилятор `javac`, `java`, `jshell`, `javadoc`, `jar`, отладчик и т.д. |

Для разработки всегда нужен **JDK**. В видео его называют SDK (Software Development Kit) — это общее название «набора разработчика» для любой платформы.

:::outdated "Отдельной JRE больше нет"
Начиная с Java 11 Oracle и другие поставщики **не выпускают отдельную JRE** для пользователей. Приложения поставляются либо с полным JDK, либо со «своей» урезанной средой выполнения, собранной утилитой `jlink`. Поэтому сейчас ставят просто JDK.
:::

### Как запускается программа

```text
Hello.java  --(javac)-->  Hello.class (байт-код)  --(java / JVM)-->  результат
```

1. Вы пишете исходник `Hello.java`.
2. Компилятор `javac` проверяет код и создаёт файл `Hello.class` с байт-кодом.
3. Команда `java` запускает JVM, которая загружает класс и выполняет его (сначала интерпретируя, а «горячие» участки компилируя JIT-компилятором в машинный код).

IntelliJ IDEA делает всё это за вас по нажатию кнопки ▶ Run.

## Установка IntelliJ IDEA (как сейчас)

1. Откройте [jetbrains.com/idea/download](https://www.jetbrains.com/idea/download/) и скачайте **IntelliJ IDEA** для своей ОС. Альтернатива — [JetBrains Toolbox App](https://www.jetbrains.com/toolbox-app/): он сам ставит и обновляет все IDE JetBrains.
2. Запустите установщик. На Windows полезно отметить:
   - **Add "bin" folder to the PATH** — чтобы открывать IDE из консоли командой `idea`;
   - **Create Associations → .java** — чтобы `.java`-файлы открывались в IDEA;
   - **Add "Open Folder as Project"** — пункт в контекстном меню проводника.
3. При первом запуске выберите тему (светлая/тёмная), импорт настроек пропустите.

:::outdated "Community и Ultimate теперь один продукт"
В видео выбирается «бесплатная версия» — **Community Edition**. С версии **2025.3** JetBrains объединила Community и Ultimate в **единый IntelliJ IDEA**. Всё, что было в Community, бесплатно и для коммерческих проектов; сверх того бесплатно добавлены мастер Spring Boot, подсветка Spring/Jakarta EE, подключение к базам данных и SQL. Расширенные функции (полная поддержка Spring, профайлер, HTTP-клиент, инструменты для БД и т.д.) работают по подписке **Ultimate** с 30-дневным пробным периодом. Студенты и преподаватели получают Ultimate бесплатно по [образовательной лицензии](https://www.jetbrains.com/community/education/). Подробнее — в разделе [IDE: где писать код](#/tools/ide).
:::

:::outdated "Новый интерфейс"
С 2023 года в IDEA по умолчанию **New UI**: кнопки Run/Debug вверху справа, инструменты (Project, Git, Terminal) — на боковых панелях-иконках. Пункты меню на видео могут выглядеть иначе, но называются так же. Главное меню скрыто под «гамбургером» ☰ слева вверху.
:::

## Установка JDK (как сейчас)

В видео JDK скачивается вручную с сайта Oracle. Сегодня проще и правильнее сделать это **прямо из IDEA**:

1. **File → New → Project** (или *New Project* на стартовом экране).
2. В поле **JDK** раскройте список → **Download JDK…**
3. Выберите **Version: 25** (актуальная LTS-версия) и **Vendor: Eclipse Temurin** (или Amazon Corretto, Azul Zulu, Oracle OpenJDK — подойдёт любой).
4. Нажмите *Download* — IDEA скачает JDK в папку пользователя (`~/.jdks`) и сразу подключит к проекту.

:::outdated "Oracle JDK и лицензия"
На видео нужно было принимать лицензионное соглашение Oracle. С 2019 по 2021 год Oracle JDK был платным для коммерческого использования, что напугало многих. Сейчас Oracle JDK распространяется по бесплатной лицензии NFTC, но в индустрии всё равно чаще используют **сборки OpenJDK** — Eclipse Temurin, Amazon Corretto, Azul Zulu, BellSoft Liberica. Технически это тот же Java. Сравнение — в статье [JDK: версии и дистрибутивы](#/tools/jdk).
:::

### Какую версию выбрать

На октябрь 2026 года:

- **Java 25** — текущая **LTS** (Long-Term Support, долгосрочная поддержка), вышла в сентябре 2025. **Учите на ней.**
- **Java 21** и **Java 17** — предыдущие LTS, их больше всего в продакшене компаний.
- **Java 27** — свежий релиз (15 сентября 2026), поддерживается полгода. Хорош для экспериментов.
- Следующая LTS — **Java 29** (сентябрь 2027).

Новые версии Java выходят **каждые 6 месяцев** (март и сентябрь), LTS — каждые 2 года.

### Проверка установки из консоли

Если вы ставили JDK отдельно (установщиком, `winget`, `brew` или SDKMAN!), проверьте:

```bash
java -version
javac -version
```

Ответ должен содержать номер версии, например `openjdk version "25.0.1"`. Если команда не найдена — JDK не добавлен в переменную `PATH` (на Windows установщики Temurin/Corretto умеют сделать это сами — отметьте пункт *Set JAVA_HOME* и *Add to PATH*).

Быстрая установка через менеджеры пакетов:

```bash
# Windows
winget install EclipseAdoptium.Temurin.25.JDK
# macOS
brew install --cask temurin@25
# Linux / macOS / WSL — SDKMAN!
sdk install java 25-tem
```

## Что не рассказано в видео

- **JAVA_HOME** — переменная окружения с путём к JDK. Её используют Maven, Gradle и другие инструменты. Установщики JDK обычно предлагают её задать.
- **Несколько JDK на одном компьютере** — нормально. В IDEA версия выбирается для каждого проекта: *File → Project Structure → Project → SDK*.
- **JShell** — интерактивная консоль Java (с Java 9). Наберите `jshell` в терминале и пишите выражения без классов и `main` — отличный способ быстро что-то проверить.
- **Запуск без IDE**: с Java 11 одиночный файл можно запустить сразу командой `java Hello.java` — без отдельной компиляции; с Java 22 так можно запускать и программы из нескольких файлов.

:::tip
Не бойтесь английского интерфейса IDEA: вся документация, ошибки компилятора и вопросы на Stack Overflow — на английском. Привыкайте с первого дня. Если очень нужно, есть официальный плагин русского/польского языка (*Settings → Plugins → Language Pack*), но лучше обойтись без него.
:::

## Домашнее задание

В этом уроке в видео задания нет — закрепим установку сами.

:::task easy "Проверка окружения"
Установите IntelliJ IDEA и JDK 25 (через *Download JDK…* в IDEA). Откройте встроенный терминал IDEA (**Alt+F12** / **⌥F12**) и выполните `java -version` и `javac -version`. Запишите, какой вендор и какая версия у вас установлены.
??? Подсказка
Если IDEA скачала JDK в `~/.jdks`, а в системном `PATH` его нет, терминал может не найти `java`. Тогда установите JDK ещё и в систему (`winget`/`brew`/SDKMAN!) или запустите `~/.jdks/<папка>/bin/java -version` по полному пути.
:::

:::task easy "Знакомство с JShell"
Запустите `jshell` и посчитайте в нём: `2 + 2 * 2`, `10 / 3`, `10 % 3`, `Math.sqrt(144)`. Выйдите командой `/exit`.
??? Подсказка
Каждое выражение просто вводится и подтверждается Enter — JShell сам выведет результат вида `$1 ==> 6`.
:::

:::task medium "Компиляция без IDE"
Создайте в любом текстовом редакторе файл `Hello.java` с классом `Hello`, который печатает `Привет, Java!`. Скомпилируйте его командой `javac Hello.java`, посмотрите, какой файл появился рядом, и запустите `java Hello`.
??? Подсказка
```java
public class Hello {
    public static void main(String[] args) {
        System.out.println("Привет, Java!");
    }
}
```
После `javac` появится `Hello.class` — это байт-код. Запускается класс по имени, **без** расширения: `java Hello`.
:::

:::task hard "Две JDK и байт-код"
Установите вторую JDK (например, 21) и переключите на неё проект в *Project Structure*. Затем скомпилируйте `Hello.java` командой `javac --release 17 Hello.java` и выполните `javap -v Hello.class | findstr major` (Windows) или `| grep major` (macOS/Linux). Какое число вы увидели и что оно означает?
??? Подсказка
`major version` — версия формата class-файла: 61 = Java 17, 65 = Java 21, 69 = Java 25. Флаг `--release` позволяет компилировать код для более старой версии Java, чем установленный JDK.
:::
