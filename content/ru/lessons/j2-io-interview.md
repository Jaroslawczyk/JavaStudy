## Вопросы

:::task video "1. Как создать новый файл?"
{{t j2 6:51:28}}
??? Ответ
`new File(path).createNewFile()` (папка должна существовать). Современно: `Files.createFile(Path.of(path))` или сразу `Files.writeString(path, text)`.
:::

:::task video "2. Как создать папку?"
{{t j2 6:51:35}}
??? Ответ
`mkdir()` — одну папку, `mkdirs()` — всю цепочку. NIO: `Files.createDirectory` / `Files.createDirectories`.
:::

:::task video "3. Как получить список файлов в папке?"
{{t j2 6:51:46}}
??? Ответ
`list()` — массив имён, `listFiles()` — массив `File`; оба принимают фильтр. NIO: `Files.list(dir)` (стрим, закрывать) или `Files.walk` для рекурсивного обхода.
:::

:::task video "4. Что общего и чем отличаются InputStream, OutputStream, Reader, Writer?"
{{t j2 6:52:07}}
??? Ответ
Все — абстрактные классы ввода-вывода. `InputStream`/`OutputStream` работают с **байтами**, `Reader`/`Writer` — с **символами** (учитывают кодировку). `InputStream`/`Reader` — ввод, `OutputStream`/`Writer` — вывод.
:::

:::task video "5. Как превратить данные из файла в поток байтов?"
{{t j2 6:52:33}}
??? Ответ
`new FileInputStream(file)` или `Files.newInputStream(path)`.
:::

:::task video "6. Какие классы ускоряют чтение/запись за счёт буфера?"
{{t j2 6:52:39}}
??? Ответ
`BufferedInputStream`, `BufferedOutputStream`, `BufferedReader`, `BufferedWriter`.
:::

:::task video "7. Зачем нужен RandomAccessFile?"
{{t j2 6:52:52}}
??? Ответ
Произвольный доступ к содержимому файла: `seek()` перемещает указатель, можно читать и перезаписывать данные в любой позиции.
:::

:::task video "8. Что такое сериализация и десериализация?"
{{t j2 6:53:13}}
??? Ответ
Сериализация — преобразование объекта (графа объектов) в поток байтов; десериализация — создание объекта из потока байтов.
:::

:::task video "9. Какие условия нужны, чтобы объект можно было сериализовать?"
{{t j2 6:53:33}}
??? Ответ
Класс реализует `Serializable` или `Externalizable`; все нестатические поля сериализуемы или `transient`; первый несериализуемый предок имеет доступный конструктор без параметров.
:::

:::task video "10. Для чего ключевое слово transient?"
{{t j2 6:53:58}}
??? Ответ
Исключает поле из сериализации; после восстановления оно имеет значение по умолчанию. Применяют для паролей, кэшей, несериализуемых ресурсов (соединений, потоков).
:::

:::task video "11. Чем отличаются Serializable и Externalizable?"
{{t j2 6:54:03}}
??? Ответ
`Serializable` — маркер, сериализация автоматическая, конструктор при чтении не вызывается. `Externalizable` — вы сами реализуете `writeExternal`/`readExternal`, при чтении вызывается public-конструктор без параметров.
:::

:::task video "12. Что такое try-with-resources?"
{{t j2 6:54:44}}
??? Ответ
Конструкция `try (ресурсы) { … }`: ресурсы (`AutoCloseable`) закрываются автоматически в обратном порядке при выходе из блока; исключения из `close()` добавляются как suppressed.
:::

## Дополнительные вопросы (не из видео)

:::task easy "Что такое serialVersionUID?"
Зачем объявлять его вручную?
??? Ответ
Номер версии класса, который JVM сверяет при десериализации. Автоматический зависит от структуры класса и компилятора, поэтому любое изменение ломает совместимость. Явное объявление (`@Serial private static final long serialVersionUID = 1L;`) даёт контроль над совместимостью версий.
:::

:::task medium "java.io vs java.nio"
Чем отличаются?
??? Ответ
`java.io` — потоковый, блокирующий API (байты/символы по порядку). `java.nio` (Java 1.4) — буферы и каналы, неблокирующий ввод-вывод с селекторами, memory-mapped файлы. NIO.2 (Java 7, `java.nio.file`) — `Path`, `Files`, обход деревьев, атрибуты, наблюдение за папками (`WatchService`).
:::

:::task medium "Почему важно указывать кодировку?"
Приведите пример ошибки.
??? Ответ
Без явной кодировки до Java 18 использовалась системная (на русской Windows — windows-1251), и файл, записанный на одной машине, читался кракозябрами на другой. С Java 18 по умолчанию UTF-8, но явный `StandardCharsets.UTF_8` делает код переносимым и понятным.
:::

:::task hard "Чем опасна десериализация?"
И как защититься?
??? Ответ
`readObject()` может создать объекты любых сериализуемых классов из classpath; подобранные данные запускают цепочки методов (gadget chains) вплоть до выполнения кода. Защита: не десериализовать недоверенные данные, использовать `ObjectInputFilter` с белым списком классов, переходить на явные форматы (JSON, Protobuf).
:::
