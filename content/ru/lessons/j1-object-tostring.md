## Object и toString()

Каждый класс в Java (если не указан другой родитель) неявно наследуется от `java.lang.Object`. Поэтому даже у пустого класса есть методы `toString()`, `equals()`, `hashCode()`, `getClass()`…

`System.out.println(box)` неявно вызывает `box.toString()`. Реализация из `Object` возвращает `ИмяКласса@хеш` — например, `Box@1b6d3586`, что ничего не говорит человеку. Переопределим:

```java
@Override
public String toString() {
    return String.format("Ширина: %s%nДлина: %s%nВысота: %s", width, length, height);
}
```

```java
System.out.println(box);
// Ширина: 10.0
// Длина: 10.0
// Высота: 10.0
```

<kbd>Alt+Insert</kbd> → **toString()** — IDEA сгенерирует метод сама в формате `Box{width=10.0, length=10.0, height=10.0}`.

## String.format

```java
String s = String.format("Привет, %s! Возраст: %d, рост: %.1f см", "Иван", 34, 166.3);
// "Привет, Иван! Возраст: 34, рост: 166,3 см" — разделитель зависит от языка системы
```

| Спецификатор | Для чего | Пример |
|---|---|---|
| `%s` | любое значение (вызовет `toString`) | `"%s"` → `Box{…}` |
| `%d` | целое число | `"%5d"` → `   42` |
| `%f`, `%.2f` | дробное, с 2 знаками | `"%.2f"` → `3.14` |
| `%n` | перевод строки (правильный для ОС) | |
| `%,d` | разделитель разрядов | `1,000,000` |
| `%-10s` | ширина 10, по левому краю | таблицы |

С Java 15 есть короче: `"Привет, %s!".formatted(name)`.

:::tip "Локаль"
`%.1f` выводит десятичный разделитель по языку системы: в RU/PL — запятую, в EN — точку. Если нужна всегда точка (например, для JSON или CSV): `String.format(Locale.ROOT, "%.1f", x)`.
:::

## Math.random() — игральный кубик

```java
int dice = (int) (Math.random() * 6 + 1);   // 1…6
```

Разбор:

1. `Math.random()` — `double` в диапазоне **[0; 1)** (единица не включается).
2. `* 6` → [0; 6).
3. `+ 1` → [1; 7).
4. `(int)` отбрасывает дробную часть → 1, 2, 3, 4, 5 или 6.

:::warning "Скобки обязательны"
`(int) Math.random() * 6 + 1` всегда даёт **1**: приведение относится только к `Math.random()`, а `(int) 0.73` = 0. Приведение типа имеет высокий приоритет — берите в скобки всё выражение.
:::

Общая формула для диапазона [min; max]: `(int) (Math.random() * (max - min + 1)) + min`.

## Что не рассказано в видео

### Удобнее, чем Math.random()

```java
import java.util.Random;
import java.util.concurrent.ThreadLocalRandom;

int a = new Random().nextInt(1, 7);                    // 1…6 (метод с двумя аргументами — Java 17+)
int b = ThreadLocalRandom.current().nextInt(10, 101);  // 10…100 — лучший выбор в многопоточности
Random seeded = new Random(42);                         // одинаковая последовательность при каждом запуске — удобно в тестах
```

Для криптографии (пароли, токены) используется только `java.security.SecureRandom`.

### equals и hashCode

Кроме `toString()`, из `Object` чаще всего переопределяют `equals()` (сравнение по содержимому) и `hashCode()` — обязательно **вместе**, иначе `HashSet`/`HashMap` будут работать неправильно. Подробно — во второй части курса (собственная реализация `HashMap` и вопросы с собеседований).

### records генерируют toString сами

```java
record Point(int x, int y) { }
System.out.println(new Point(3, 4));   // Point[x=3, y=4]
```
