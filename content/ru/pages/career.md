# Карьера: куда двигаться после Java

Курс даёт фундамент **Java SE** — язык, коллекции, многопоточность, ввод-вывод. Чтобы получить первую работу Java-разработчиком, нужно добавить к нему **backend-стек**: базы данных, Spring Boot, API, Docker, Git и умение работать в команде. Эта страница — подробная карта следующего шага. Интерактивная версия — во вкладке **[Backend Roadmap](#/roadmap/backend)**: нажмите на узел, и вы попадёте в нужный раздел.

:::tip "Порядок важнее количества"
Не пытайтесь выучить всё сразу. Работающий минимум для Junior: **Java + SQL/PostgreSQL + Spring Boot + REST + Git + Docker + тесты**. Остальное (Kafka, Kubernetes, облака) — по мере роста и под конкретные вакансии.
:::

## Как работает интернет {#internet}

Бэкенд-разработчик должен понимать, что происходит между браузером и сервером:

- **HTTP/HTTPS**: методы, коды ответов (2xx/3xx/4xx/5xx), заголовки, cookies, кеширование, HTTP/2 и HTTP/3. Поэкспериментируйте с `curl -v` и вкладкой Network в DevTools.
- **DNS**: как домен превращается в IP-адрес, записи A, CNAME, MX, TXT.
- **TLS**: сертификаты, зачем нужен HTTPS, что делает Let's Encrypt.
- **Linux и терминал**: серверы почти всегда на Linux. Навигация, права, процессы (`ps`, `top`), логи (`journalctl`, `tail -f`), сеть (`ss`, `curl`), SSH.

## Git и командная работа {#git}

- **Git**: commit, branch, merge vs rebase, разрешение конфликтов, `.gitignore`, понятные сообщения коммитов.
- **GitHub/GitLab**: pull/merge request, code review, issues. Ваше портфолио — это публичные репозитории с README.
- **Процессы**: Scrum/Kanban, Jira, ежедневные встречи, оценка задач. Работодатели ценят умение работать в процессе не меньше, чем знание фреймворков.

Обзор инструментов — в статье [Экосистема](#/tools/ecosystem).

## Реляционные базы данных {#databases}

Самый востребованный навык после самой Java.

- **SQL**: `SELECT` с `JOIN`, `GROUP BY`, подзапросы, оконные функции; `INSERT/UPDATE/DELETE`.
- **Проектирование**: первичные и внешние ключи, нормализация, связи 1:N и N:M.
- **Индексы**: B-tree, когда индекс помогает и когда мешает, `EXPLAIN ANALYZE`.
- **Транзакции**: ACID, уровни изоляции, блокировки, deadlock в БД.
- **PostgreSQL** — выбор номер один для новых проектов (актуальная версия — 18). Также встречаются MySQL/MariaDB, Oracle и MS SQL (банки, корпорации).
- **Из Java**: JDBC, JPA/Hibernate, Spring Data, миграции Flyway/Liquibase — подробно в статье [Доступ к БД](#/extra/database-access).

## API {#apis}

- **REST**: ресурсы и HTTP-методы, коды ответов, идемпотентность, пагинация, версионирование, ошибки в формате Problem Details (RFC 9457).
- **JSON** и его сериализация (Jackson).
- **OpenAPI/Swagger**: документация и генерация клиентов (springdoc-openapi).
- **gRPC** (Protobuf, HTTP/2) — для общения микросервисов; **GraphQL** — для гибких клиентских запросов. Знакомство полезно, но не обязательно для Junior.

Как написать API на Spring Boot — в статье [Веб-фреймворки](#/extra/web-frameworks).

## Безопасность {#security}

- **Аутентификация и авторизация**: сессии и cookies, **JWT**, **OAuth 2.0 / OpenID Connect** (Keycloak, Auth0, Entra ID), роли и права.
- **Spring Security**: цепочка фильтров, resource server, method security.
- **OWASP Top 10**: SQL-инъекции, XSS, CSRF, небезопасная десериализация, утечки секретов, уязвимые зависимости.
- **Пароли** — только bcrypt/Argon2 ([Криптография](#/extra/cryptography)); секреты — не в Git.

## Кеширование {#caching}

- Где кешировать: в памяти приложения (**Caffeine**), распределённо (**Redis** или его открытый форк **Valkey**), на уровне HTTP (`Cache-Control`, ETag, CDN).
- **Spring Cache** (`@Cacheable`) поверх любого провайдера.
- Проблемы: инвалидация, «прогрев», устаревшие данные, cache stampede. Кеш — это компромисс между скоростью и актуальностью.

## Контейнеры и инфраструктура {#containers}

- **Docker**: образ, контейнер, `Dockerfile` (многоэтапная сборка, `eclipse-temurin` как базовый образ), `docker compose` для локального окружения (приложение + PostgreSQL + Redis).
- **Kubernetes**: Pod, Deployment, Service, ConfigMap/Secret, Ingress, health-пробы (Spring Boot Actuator). Для Junior достаточно понимать концепции; детали придут на работе.
- **Веб-серверы и прокси**: Nginx, балансировщики, TLS-терминация.

## CI/CD {#cicd}

**Continuous Integration / Delivery** — каждый push автоматически собирается, тестируется и (при успехе) выкатывается.

- **GitHub Actions**, **GitLab CI**, Jenkins (наследие, но распространён в корпорациях).
- Типичный конвейер: сборка → тесты → статический анализ (SonarQube) → сборка Docker-образа → деплой на тестовую среду → продакшен.
- Проверка зависимостей на уязвимости (Dependabot, Renovate, OWASP Dependency-Check).

Совет: настройте GitHub Actions для своего учебного проекта — это заметный плюс в резюме.

## Архитектура {#architecture}

- **Монолит, модульный монолит, микросервисы** — плюсы и минусы. Большинство новых проектов разумно начинать с хорошо структурированного монолита (Spring Modulith).
- **Слоистая и гексагональная архитектура**, разделение на контроллеры, сервисы, репозитории.
- **Паттерны GoF**: Strategy, Factory, Builder, Observer, Decorator, Adapter, Template Method.
- **Принципы**: SOLID ([урок](#/lessons/j2-oop-principles)), DRY, KISS, YAGNI, 12-factor app.
- **Для роста**: DDD, CQRS, Event Sourcing, Saga, Outbox — темы Middle/Senior.

## Брокеры сообщений {#messaging}

Асинхронное общение сервисов через очереди и топики.

- **Apache Kafka** — стандарт для событийных систем и потоковой обработки (с версии 4.0 работает без ZooKeeper, на KRaft). Очень часто встречается в вакансиях Польши и Европы — особенно в банках, e-commerce и финтехе.
- **RabbitMQ** — классический брокер очередей с гибкой маршрутизацией.
- Понятия: producer/consumer, топик и партиция, consumer group, гарантии доставки (at-least-once, exactly-once), идемпотентность обработчиков. В Spring — Spring for Apache Kafka, Spring AMQP.

## NoSQL {#nosql}

- **MongoDB** — документная база (JSON-документы), Spring Data MongoDB.
- **Redis/Valkey** — key-value в памяти: кеш, сессии, очереди, rate limiting.
- **Elasticsearch/OpenSearch** — полнотекстовый поиск и аналитика логов.
- **Cassandra** — огромные объёмы записи с горизонтальным масштабированием.

Правило: NoSQL — дополнение к реляционной базе под конкретную задачу, а не её замена «потому что модно».

## Наблюдаемость и масштабирование {#observability}

- **Три столпа**: логи ([Логирование](#/extra/logging)), **метрики** (Micrometer → Prometheus → Grafana), **трейсинг** (OpenTelemetry, Jaeger/Tempo).
- **Spring Boot Actuator**: `/health`, `/metrics`, `/prometheus`.
- **Масштабирование**: горизонтальное (больше экземпляров) против вертикального, stateless-сервисы, балансировка, репликация и шардинг БД.
- **Отказоустойчивость**: таймауты, ретраи, circuit breaker (Resilience4j), graceful degradation.

## Облака {#cloud}

- **AWS** — лидер рынка (EC2, S3, RDS, Lambda, SQS/SNS, EKS).
- **Microsoft Azure** — популярен в корпорациях и банках Европы.
- **Google Cloud** — встречается реже, сильны данные и Kubernetes (GKE).

Для Junior достаточно понимать базовые сервисы одного облака. Бесплатные уровни (free tier) позволяют попрактиковаться; сертификаты (AWS Cloud Practitioner, AZ-900) — приятный, но не обязательный бонус.

## Актуальный стек 2026 {#stack}

| Уровень важности | Технологии |
|---|---|
| **Must have** | Java 21/25 (LTS), Spring Boot 3.x/4.x, Spring Data JPA/Hibernate, PostgreSQL и SQL, REST, Maven или Gradle, Git, JUnit + Mockito, Docker |
| **Очень часто** | Spring Security, Kafka, Testcontainers, Kubernetes, CI/CD (GitHub Actions/GitLab CI), Redis, микросервисы, OpenAPI |
| **Плюс** | AWS/Azure, Kotlin, Quarkus/Micronaut, MongoDB, Elasticsearch, observability (Prometheus/Grafana/OpenTelemetry), GraphQL/gRPC, Spring AI |
| **Soft skills** | английский B1–B2+, code review, работа в Scrum, умение объяснять решения |

:::note "Kotlin на бэкенде"
Kotlin работает на JVM, полностью совместим с Java и Spring и популярен в части продуктовых компаний. Учить его стоит **после** уверенной Java — переход займёт пару недель.
:::

## Европа и удалённая работа {#europe}

- **Крупные Java-рынки**: Германия (Берлин, Мюнхен, Франкфурт), Нидерланды, Ирландия, Польша, Испания и Португалия (хабы международных компаний), Скандинавия, Швейцария (высокие зарплаты, высокие требования).
- **Язык**: в международных командах — английский; знание местного языка (немецкий, нидерландский, польский) заметно расширяет выбор, особенно для Junior.
- **Переезд**: EU Blue Card и национальные программы для IT-специалистов; многие компании помогают с релокацией.
- **Удалёнка**: вакансий «remote» стало меньше, чем в 2021–2022, конкуренция за них высокая — особенно на уровне Junior. Частые условия: проживание в ЕС или конкретной стране, пересечение по часовым поясам (CET ± 2–3 часа), английский B2+, умение работать асинхронно (письменная коммуникация, самоорганизация).
- **Формы сотрудничества**: трудовой договор; контракт B2B (как предприниматель); работа через EoR-платформы (Deel, Remote.com).

:::warning "Гражданство и санкции"
Для граждан некоторых стран (в частности, России и Беларуси) часть работодателей, банков и платёжных сервисов в ЕС вводит дополнительные проверки или ограничения — например, при работе с финансовыми и государственными заказчиками. Уточняйте условия заранее и следите за актуальными правилами; при сложной ситуации стоит проконсультироваться с юристом по миграционному праву.
:::

## Варшава и Польша {#warsaw}

Польша — один из крупнейших IT-рынков Европы, и **Java — самый востребованный бэкенд-язык** в польских вакансиях. Основные хабы: **Варшава**, Краков, Вроцлав, Гданьск/Труймясто, Познань, Лодзь, Катовице.

**Кто нанимает Java-разработчиков:**
- **Банки и финтех** — центры технологий и сервисов крупных банков и финансовых групп; много Java + Spring + Kafka + Oracle/PostgreSQL.
- **Аутсорсинг и консалтинг** — software house'ы и международные сервисные компании; хороший вход для Junior, много разных проектов.
- **Продуктовые компании** — e-commerce, медтех, SaaS; чаще микросервисы, облака, Kotlin.
- **R&D-центры международных корпораций** — крупные инженерные офисы в Варшаве, Кракове, Вроцлаве и Гданьске.

**Формы договора:**
- **UoP** (umowa o pracę) — трудовой договор: отпуск, больничный, социальные взносы; «на руки» меньше.
- **B2B** — работа как ИП (JDG): выше сумма, но налоги, ZUS и бухгалтерия на вас, нет оплачиваемого отпуска по закону (часто оговаривается в контракте).

**Зарплаты (ориентир на 2025–2026, Java, Варшава, в месяц):** Junior — примерно 7–12 тыс. PLN брутто на UoP или 8–13 тыс. PLN нетто+VAT на B2B; Regular (Middle) — 15–23 тыс. PLN на B2B; Senior — 22–32 тыс. PLN и выше на B2B. Цифры сильно зависят от компании, домена и английского — **проверяйте свежие отчёты** justjoin.it, No Fluff Jobs и Bulldogjob: в польских вакансиях вилка указывается почти всегда.

:::note "Рынок для Junior"
С 2023 года стартовых вакансий в Польше заметно меньше, а откликов на каждую — сотни. Выделиться помогают: законченный проект на GitHub (Spring Boot + PostgreSQL + Docker + тесты + CI), стажировки и академии в крупных компаниях (набор обычно весной и осенью), английский B2, польский хотя бы A2–B1 и активность в сообществе (митапы, Java User Groups).
:::

## Проект для портфолио {#portfolio}

Один хороший проект лучше пяти учебных. Пример: **сервис бронирования** (столиков, мероприятий, переговорных).

1. Spring Boot 4 + Java 25, PostgreSQL, Flyway, Spring Data JPA.
2. REST API с валидацией, OpenAPI-документацией и обработкой ошибок.
3. Spring Security + JWT, роли пользователь/администратор.
4. Тесты: JUnit + Mockito + Testcontainers.
5. Docker Compose для запуска одной командой, GitHub Actions для CI.
6. Бонус: Kafka для уведомлений, Redis-кеш, метрики Prometheus/Grafana, деплой в облако.
7. README: что делает проект, как запустить, архитектурная схема, чему вы научились.
