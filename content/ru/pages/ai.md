# ИИ и Java-разработчик

ИИ-ассистенты за пару лет стали обычным инструментом разработчика — как IDE или Git. Они дописывают код, объясняют ошибки, пишут тесты и даже выполняют задачи целиком. Это меняет и то, как учиться, и то, что ждут от Junior. Разберёмся без хайпа: какие есть инструменты, как использовать их, чтобы **учиться, а не разучиться**, и какие ИИ-технологии появились в самом Java-стеке.

## Какие бывают ИИ-ассистенты {#assistants}

| Тип | Что делает | Примеры |
|---|---|---|
| **Автодополнение** | предлагает следующую строку/блок прямо в редакторе | GitHub Copilot, JetBrains AI (Full Line и облачное дополнение), Tabnine |
| **Чат в IDE** | объясняет код, отвечает на вопросы, генерирует фрагменты по запросу | JetBrains AI Assistant, Copilot Chat, Gemini Code Assist, Amazon Q Developer |
| **Агенты** | сами читают проект, меняют несколько файлов, запускают сборку и тесты, исправляют ошибки | Claude Code, JetBrains Junie, Copilot agent mode, Cursor |
| **Чат-боты общего назначения** | объяснения, разбор концепций, подготовка к интервью | Claude, ChatGPT, Gemini |

**Для IntelliJ IDEA**: встроенный AI Assistant и агент Junie от JetBrains (есть бесплатный уровень с ограниченной квотой, расширенные возможности — по подписке), плагины GitHub Copilot и Claude Code. **VS Code**: Copilot, Claude Code, Continue (можно подключить локальные модели через Ollama). Подробности о плагинах — в статье [Плагины](#/tools/plugins).

:::warning "Что нельзя отправлять в ИИ"
Код и данные работодателя — только в инструменты, одобренные компанией. Никогда не вставляйте в публичные чат-боты пароли, ключи API, персональные данные клиентов (это ещё и нарушение GDPR/RODO) и коммерческую тайну. Многие компании используют корпоративные версии ассистентов с запретом обучения на их коде.
:::

## Как учиться с ИИ и не разучиться {#learning}

ИИ может решить любое задание из этого курса за секунды. Если позволить ему это делать, вы получите зелёные тесты — и пустую голову на собеседовании. Правила, которые работают:

1. **Сначала сами.** Решайте задачу без ИИ хотя бы 20–30 минут. Застряли — просите **подсказку**, а не решение: «Не пиши код. Подскажи, в каком направлении думать».
2. **Просите объяснения, а не ответы.** «Объясни, почему здесь `ConcurrentModificationException`», «Чем `HashMap` отличается от `ConcurrentHashMap` внутри?» — ИИ отличный терпеливый репетитор.
3. **Код ИИ — на ревью.** Читайте каждую строку, которую вставляете. Если не можете объяснить строку — не вставляйте её. Ассистенты уверенно ошибаются: используют устаревшее API, выдумывают методы, пропускают граничные случаи.
4. **Проверяйте фактами.** Документация (docs.oracle.com, docs.spring.io), запуск кода и тесты — источник истины, а не ответ модели.
5. **Ревёрс-режим.** Напишите решение сами, затем попросите ИИ найти в нём ошибки и предложить улучшения — так вы учитесь на собственном коде.
6. **Тренируйте интервью.** «Проведи со мной собеседование по многопоточности Java, задавай по одному вопросу и оценивай ответы» — отличная практика перед реальным интервью.

:::tip "Хороший промпт"
Давайте контекст и ограничения: версию Java и Spring, что уже пробовали, текст ошибки целиком, какой результат нужен. Сравните: «не работает HashMap» и «Java 25, свой класс `Point` как ключ HashMap, `get` возвращает null после изменения поля `x` — почему?».
:::

## ИИ в самом Java-стеке {#stack}

ИИ — это не только помощник в IDE, но и часть приложений, которые вы будете писать. Типичные задачи бэкенда: чат-бот поддержки, поиск по документам компании, классификация обращений, извлечение данных из PDF, генерация описаний товаров.

| Технология | Что это |
|---|---|
| **Spring AI** | официальный проект Spring: единый API для моделей (OpenAI, Anthropic, Google, Mistral, Ollama и др.), structured output в Java-объекты, tool calling, RAG, интеграция с векторными БД |
| **LangChain4j** | популярная Java-библиотека для LLM-приложений: AI Services, память чата, инструменты, RAG; интеграции с Quarkus и Spring |
| **Официальные SDK** | Java SDK от OpenAI, Anthropic, Google — прямой доступ к API |
| **Векторные БД** | **pgvector** (расширение PostgreSQL), Elasticsearch/OpenSearch, Qdrant, Weaviate, Milvus |
| **RAG** | Retrieval-Augmented Generation: документы режутся на фрагменты, превращаются в эмбеддинги, похожие фрагменты находятся поиском и передаются модели как контекст |
| **MCP** | Model Context Protocol — открытый стандарт, по которому ИИ-агенты подключаются к инструментам и данным; есть официальный Java SDK, интеграция в Spring AI |
| **Локальные модели** | Ollama, LM Studio — запуск открытых моделей на своём компьютере, без отправки данных наружу |

```java
// Spring AI: ответ модели сразу в виде Java-объекта
record Sentiment(String label, double score) {}

Sentiment s = chatClient.prompt()
        .user("Оцени тональность отзыва: " + review)
        .call()
        .entity(Sentiment.class);
```

Для Junior в 2026 году знание Spring AI или LangChain4j — заметный плюс в резюме: сделайте небольшой проект «вопрос-ответ по своим документам» на Spring Boot + pgvector.

:::note "Регулирование ИИ в ЕС"
EU AI Act вводит требования к ИИ-системам поэтапно: например, пользователей нужно информировать, что они общаются с ИИ, а сгенерированный контент в ряде случаев должен быть помечен. Для систем высокого риска (кредитный скоринг, найм, медицина) требования намного строже. Если делаете ИИ-функции для пользователей в ЕС, учитывайте это с самого начала.
:::

## Как ИИ меняет работу и найм {#jobs}

- **Рутинного кода пишут меньше**, больше времени уходит на постановку задачи, проектирование, ревью и проверку результата. Умение **читать и оценивать чужой код** стало ещё важнее.
- **Планка для Junior выросла.** Компании ждут, что новичок использует ИИ продуктивно, но понимает основы: на собеседовании ИИ обычно недоступен, а live-coding и вопросы по Java SE остались. Курс и задачи на этом сайте — именно та база.
- **Новые навыки в вакансиях**: «опыт работы с GitHub Copilot/AI-инструментами», «интеграция LLM», «Spring AI/LangChain4j», «RAG».
- **Ответственность остаётся за вами.** Код, сгенерированный ИИ, коммитите вы — и отвечаете за его корректность, безопасность и лицензионную чистоту.

:::interview "Что могут спросить про ИИ на интервью"
«Как вы используете ИИ в работе?» — Хороший ответ показывает зрелость: для чего используете (тесты, рутина, объяснения, поиск ошибок), как проверяете результат (ревью, тесты, документация), чего не делаете (не отправляете секреты, не коммитите непонятый код).
:::

## Кратко

- Используйте ИИ как **репетитора и напарника**, а не как исполнителя домашних заданий.
- Всё, что сгенерировано, — **читать, понимать, тестировать**.
- Изучите хотя бы один ИИ-фреймворк для Java (**Spring AI** или **LangChain4j**) — это актуальный плюс к стеку из раздела [Карьера](#/page/career).
