# JavaStudy: Java from zero to Junior+

A free Java textbook built on Andrey Sumin's video course (≈ 17.5 hours of video in two parts) and extended with everything you need in 2026: current Java versions, tools, roadmaps, career advice and AI.

## How to learn here

1. **Start with [Tools](#/tools/ide)** — pick an IDE, install a JDK and useful plugins.
2. **Go through the lessons in order.** Every lesson has timestamps like {{t j1 0:00 ▶}} — click one and the video opens in a small player right on this page at the exact second. The video is in Russian: turn on YouTube's auto-translated subtitles, or simply learn from the text — every lesson is fully written out in English.
3. **Read the notes**: they contain what is said in the video, plus what is *not* covered there, and **↻ Outdated** markers — what has changed in newer Java versions and tools.
4. **Solve the homework** at the end of each lesson: the task from the video plus extra exercises from ● easy to ◆ hard. Hints are hidden — open them only when you are stuck.
5. **Mark lessons as completed** — progress is saved in this browser and shown in the menu and on the [Roadmap](#/roadmap).

:::tip "Accessibility"
The **Aa** button in the header opens the settings: theme (coffee light / GitHub dark), color-blind mode, font size, spacing and a high-legibility font.
:::
